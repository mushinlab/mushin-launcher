# G. Глоссарий

| Термин | Определение |
|---|---|
| **Энв (Environment)** | Именованный контекст: палитра + упорядоченный набор избранного + своя история поиска. Типы: NORMAL (ровно один, неудаляемый), WORK (≤ 1), CUSTOM (≤ 20). |
| **Текущий энв** | Энв из `current_env_id`; определяет всё, что видно на Home и в recents. |
| **Избранное** | Упорядоченные элементы `environment_item` энва, показываемые на Home. |
| **Компонент** | Пара `(ComponentName, UserHandle)`; в БД — `(package_name, activity_name, user_serial)`. |
| **Recents** | Правая треть экрана поиска: недавние запуски **из поиска** в текущем энве, без элементов его избранного. |
| **Зебра** | Чередование фонов `zebraA` / `zebraB` у соседних строк на всю ширину для явной тап-зоны. |
| **Палитра** | Набор цветовых ролей C.5. |
| **Фильтр иконок** | Конвейер D.7: монохромный слой или обесцвечивание, затем тонирование `iconTint`. |
| **Popup** | Anchored-панель под точкой long-press: энвы, divider, ⚙ (и секция приложения на строке). |
| **Встроенная клавиатура** | Composable-клавиатура лаунчера, не IME. |
| **Раскладочный своп** | Перевод набранного по физическим позициям клавиш RU↔EN («ыдфсл» → «slack»). |
| **Транслит** | Перевод кириллицы в латиницу по D.11 («слак» → «slak»). |
| **Фонетический ключ** | Нормализованная латинская форма для сравнения (`slack` и `слак` → `slak`). |
| **Биндинг жеста** | Действие на свайп в направлении UP/DOWN/LEFT/RIGHT. |
| **Режим Browsing** | Поиск со свёрнутой клавиатурой (ALL_APPS, аппаратная клавиатура). |
| **Safe-area** | Область экрана без системных баров и выреза, с полем 8dp. |
| **Кадр** | Один vsync устройства (11,1 мс на 90 Гц). |
| **ADR** | Architecture Decision Record — неизменяемое зафиксированное решение. |

# Caveats

- **Хрупкое — шторка уведомлений.** Скрытый `expandNotificationsPanel` на API 37 официально не документирован. Его работоспособность подтверждена только коммитами открытых лаунчеров. Проверить на целевом устройстве в первой же задаче T5.3.
- **Расхождения в официальных источниках по Android 17.**
  - Отказ от пересоздания Activity при CONFIG_KEYBOARD и подобных изменениях описан в анонсе Beta 1, но отсутствует на актуальных страницах behavior changes. Поэтому `configChanges` объявлены явно.
  - Пункт о `usesCleartextTraffic` в блоге и в документации расходится. На нас он не влияет: сети нет.
- **Сроки поддержки Pixel 6.** Google формулирует политику как «5 лет с начала продаж в Google Store США». Окончание поддержки 6/6 Pro Google прямо подтвердила в release notes Android 17 QPR2 Beta 1. Июль 2027 для 6a — вывод из даты начала продаж.
- **Версии тулчейна** взяты на 1 октября 2026 из официальной документации Compose и публичных PR. Точные версии Room, KSP, benchmark и profileinstaller агент фиксирует в E0 по Google Maven и после этого не меняет без ADR.
- **Числовые цели производительности** (TTID ≤ 350 мс и т. п.) — проектные, а не измеренные. Их нужно откалибровать после первого замера в E11. Если цель недостижима, она пересматривается через ADR, а не молча.
