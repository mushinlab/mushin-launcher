# A. Бизнес-анализ

## A.1 Видение продукта

«Энв» — лаунчер, который за одно касание выдаёт нужное приложение и ничего больше. Он мгновенный и монохромный, без уведомлений, лент и анимаций. Набор приложений и палитра переключаются под контекст жизни — «энв»: обычный, работа, свой.

## A.2 Цели (измеримые)

| ID | Цель | Метрика | Целевое значение |
|---|---|---|---|
| G1 | Мгновенность | Задержка от второго DOWN двойного тапа до кадра с клавиатурой | ≤ 1 кадр (≤ 11,1 мс на 90 Гц Pixel 6, ≤ 8,3 мс на 120 Гц 6 Pro) |
| G2 | Быстрый холодный старт | TTID, медиана, Macrobenchmark, с Baseline Profile | ≤ 350 мс; P95 ≤ 500 мс |
| G3 | Точный поиск | Доля запусков из поиска, где выбран результат №1 | ≥ 90 % (локальная статистика, v1.1) |
| G4 | Стабильность | Падения и убийства MemoryLimiter за 14 дней ежедневного использования | 0 |
| G5 | Отсутствие отвлечений | Цветные элементы, бейджи, анимации на главном экране | 0 |

## A.3 Персона

**Владелец-разработчик.** Пользуется Pixel 6 с Android 17 и жестовой навигацией. Свободно печатает на ЙЦУКЕН и QWERTY и часто набирает в неправильной раскладке. Держит 8–10 избранных приложений в каждом контексте, остальное ищет. Разделяет личное и рабочее, рабочий профиль возможен. Ценит скорость и предсказуемость выше красоты, раздражается от задержек системной клавиатуры (около 200 мс).

## A.4 Решаемые проблемы

1. Сетка цветных иконок провоцирует бесцельные запуски. Решение: текст плюс обесцвеченные иконки.
2. Системный поиск открывается долго: клавиатура появляется с анимацией, жест «вниз» конфликтует со шторкой.
3. Набор нужных приложений зависит от контекста, а Pixel Launcher контексты не поддерживает.
4. Набор в неправильной раскладке и транслит («слак», «ыдфсл») ничего не находит.

## A.5 Принципы (критерии для спорных решений)

1. **Скорость важнее функций.** Фича, которая ухудшает G1 или G2, не принимается.
2. **Ноль анимаций.** Все переходы мгновенные. Исключение — системные анимации, которые нельзя отключить: запуск приложения и predictive back-to-home.
3. **Явность.** Каждая тап-зона видима (зебра), каждое действие обратимо или подтверждается.
4. **Монохром.** Цвет — только у палитры энва. Цвета приложений не допускаются.
5. **Без сети.** Разрешения INTERNET нет.
6. **Одна Activity.** Главный экран, поиск и popup — это состояния одной композиции.

## A.7 Предположения и открытые вопросы (с ответами по умолчанию)

| # | Вопрос | Ответ по умолчанию (агент применяет без уточнений) |
|---|---|---|
| Q1 | Нужен ли отдельный экран «Все приложения»? | Нет. Поиск с пустым запросом показывает все видимые приложения по алфавиту. Жест-действие ALL_APPS открывает поиск в режиме просмотра (клавиатура свёрнута). |
| Q2 | Что делает long-press на строке приложения? | Открывает тот же popup, но с секцией приложения сверху: «Об приложении», «Переименовать», «Скрыть», «Убрать из энва», «Удалить». Ниже — divider, энвы, divider, шестерёнка. Так требование «long-press по любой области» выполняется буквально. |
| Q3 | Enter в поиске? | Запускает результат №1. Если результатов нет — haptic REJECT, состояние не меняется. |
| Q4 | Скроллится ли список на главном экране? | Нет. Максимум строк = floor(доступная высота / высота строки). В редакторе нельзя добавить больше; кнопка «Добавить» неактивна с подписью «Максимум N». Так снимается конфликт свайпов со скроллом. |
| Q5 | Пробел на клавиатуре? | Нет: только буквы. Пробелы и знаки при сопоставлении игнорируются. Многословные названия находятся по инициалам («gm» → Google Maps) и слитному набору («googlemaps»). |
| Q6 | Буква «ё»? | Отдельной клавиши нет. При нормализации ё → е. |
| Q7 | Портрет? | Заблокирован (`screenOrientation="portrait"`). На sw ≥ 600dp система это проигнорирует; вёрстка обязана не ломаться и в альбомной ориентации. |
| Q8 | Обои? | В MVP фон сплошной, из палитры энва (`windowShowWallpaper=false`). Прозрачный вариант — F19. |
| Q9 | Жесты общие или по энвам? | Общие (F22 — backlog). |
| Q10 | Как вводить текст в настройках (имя энва, переименование)? | Можно использовать стандартный `TextField` с системным IME. Запрет системной клавиатуры действует **только** на экране поиска. |
| Q11 | Сколько энвов допускается? | 1 NORMAL (не удаляется), не более 1 WORK, до 20 CUSTOM. |
| Q12 | Удаление приложения | Удаляются его строки из `environment_item`, `search_recent`, `app_usage`. `app_override` сохраняется на 30 дней на случай переустановки, затем удаляется при старте. |
| Q13 | Анимации popup и клавиатуры | Нет (0 мс). |
| Q14 | Лицензия проекта | Сейчас — приватный репозиторий без лицензии. Перед публикацией владелец выбирает Apache-2.0, если GPL-кода нет, или GPL-3.0-or-later, если код референсов всё же заимствуется. |

## A.8 Риски и митигация

| # | Риск | Тип | Вероятность / влияние | Митигация |
|---|---|---|---|---|
| R1 | Скрытый API шторки перестанет работать (greylist → blocklist) | Платформа | Низкая на замороженном Pixel 6; средняя на новом устройстве | Вызов в try/catch за интерфейсом `NotificationShade`. При ошибке — одноразовый Snackbar-тост. Fallback F25 в backlog. |
| R2 | MemoryLimiter убивает лаунчер | Платформа | Средняя / высокое | LruCache иконок ≤ 8 МБ, bitmap'ы иконок ≤ 96 px, `onTrimMemory` → очистка. Тест: `am memory-limiter status`. Целевой PSS ≤ 60 МБ. |
| R3 | Задержка двойного тапа (300 мс) просачивается в запуск приложений | UX | Высокая при наивной реализации | Собственный детектор: на строках двойной тап не распознаётся, на фоне одиночный тап ничего не делает (D.9). |
| R4 | Первый кадр поиска дорогой (композиция клавиатуры) | Производительность | Средняя | Слой поиска всегда скомпонован и скрыт через `graphicsLayer { alpha = 0 }` + `Modifier.pointerInput` disabled; Baseline Profile покрывает путь открытия. |
| R5 | Нарушение GPL при заимствовании кода | Лицензия | Средняя при работе AI-агента | Правило в CLAUDE.md: «не открывать и не копировать исходники GPL-референсов». Опираться только на эту спецификацию и документацию Android. |
| R6 | Pixel 6/6 Pro без патчей безопасности после октября 2026 | Платформа | Высокая / среднее | Лаунчер без INTERNET. minSdk 33 и отсутствие хаков под конкретное устройство упрощают переезд на новое. |
| R7 | Нестабильность AGP 9 / Kotlin 2.4 / KSP | Тулчейн | Средняя | Версии фиксируются в `libs.versions.toml`, Renovate с ручным merge, CI-гейт. |
| R8 | Конфликт свайпов с системными жестами | UX | Средняя | Стартовые зоны вне `systemGestures` / `mandatorySystemGestures`, пороги из C.4. |
| R9 | Неоднозначность спецификации, из-за которой агент «додумывает» | Процесс | Высокая | Раздел «Зафиксированные решения», DoD с проверяемыми тестами, запрет менять решения без ADR. |

## A.9 Метрики успеха (как измерять)

- G1: инструментальный тест с `ComposeTestRule` и `FrameTimingMetric` плюс трассировка Perfetto (секция `search_open` от `Trace.beginSection` на втором DOWN до `Choreographer#doFrame`, в котором клавиатура отрисована).
- G2: модуль `:benchmark`, `StartupTimingMetric`, `StartupMode.COLD`, 10 итераций, `CompilationMode.Partial(BaselineProfileMode.Require)`.
- G3: локальный счётчик `search_launch(rank)` (только в debug-экране «Статистика», без сети).
- G4: `ApplicationExitInfo` при старте. Причины с `"MemoryLimiter"` записываются в локальный лог в debug-экране.
