# Редактирование главного экрана и визуальный отклик

Актуализация по [ADR-0037](../adr/0037-edit-controls-widgets-and-touch-feedback.md), 2026-11-07. Предыдущие правила действуют в части, не заменённой этим ADR. Панель виджетов заменена по [ADR-0039](../adr/0039-compact-top-widget-panel.md).

- **AC-37.1.** Given режим редактирования, When пользователь нажимает приложение или папку, Then открывается минимодалка: название, «Убрать из списка», «Заменить» в указанном порядке. В самой строке кнопок редактирования и удаления нет. У приложения «Заменить» сохраняет место строки и открывает выбор замены; у папки открывает её редактор. Удаление папки не удаляет приложения с устройства.
- **AC-37.2.** Given режим редактирования, When пользователь нажимает нижнюю кнопку «?», Then поверх главного экрана открывается минимодалка советов с разделами «Список приложений и папки», «Виджеты», «Шрифт», «Тема». When Back, Then минимодалка закрывается, режим редактирования остаётся. Вне режима кнопки советов редактирования нет.
- **AC-37.3.** Given активная кнопка или кнопка-иконка, When нажатие в произвольной точке, Then из этой точки распространяется обрезанный границами элемента радиальный градиент, который исчезает при отпускании. Каждый переход ≤ 200 мс. Масштабирования и выбора прежних пяти стилей нет.
- **AC-37.4.** Given любая фиксированная тема и произвольное изображение фона, Then кнопки-иконки имеют непрозрачные подложки из темы. Контраст значка к подложке ≥ 3:1. Активное редактирование обозначено акцентной скруглённой квадратной кнопкой. Список тем не меняется.
- **AC-37.6.** Given «Ввод жестами» выключен, Then подчинённые настройки остаются видимыми и приглушёнными, их действия и accessibility-действия недоступны. Переключатель находится справа от названия секции. When включение, Then действия доступны с сохранёнными значениями.
- **AC-37.7.** Given минимодалка добавления жеста, Then между подсказкой и клавиатурой фиксированный небольшой отступ, а высота определяется содержимым и доступным экраном, без растягивания до 70% экрана.
- **AC-37.8.** Given рисование жеста на главном экране или клавиатуре, Then след — непрерывный сглаженный силуэт; за 200 мс старые точки теряют толщину и исчезают, без цепочки кругов на стыках. Распознавание получает исходные координаты и время независимо от визуального следа.
- **AC-37.9.** Given «Ввод жестами» включён, When рисунок на главном экране совпал с выученным жестом ровно одного приложения, Then это приложение сразу запускается, без поиска. When совпали жесты нескольких приложений, Then открывается поиск с этими приложениями в подсказках. When совпадений нет, Then промах отвергается вибрацией.

- **AC-39.1.** Given главный экран, Then панель виджетов только сверху; встроенные часы — обычная ячейка панели (по умолчанию первая) и входят в её лимит. Given редактирование, Then на часах кнопка «Настроить» по центру (минимодалка «Часы»: формат, размер, дата) и «Убрать» в углу, на остальных ячейках — «Убрать»; содержимое ячейки центрировано; часы переносятся как любой виджет. Given часы убраны, Then они доступны первым пунктом выбора виджета, выбор открывает минимодалку «Часы». Given пустая панель, Then вне редактирования она не занимает места; в редактировании каждая свободная ячейка — ячейка добавления, и виджет добавляется в неё (ADR-0040).
- **AC-39.2.** Given панель, Then это сетка 2×2; виджет занимает 1×1, 2×1, 1×2 или 2×2 без пересечений; вне редактирования пустые строки не занимают места. Given редактирование, When удержание и перенос, Then рамка показывает цель, и виджет встаёт туда, занятые виджеты переезжают в свободные ячейки (перенос на занятую ячейку меняет местами, даже если раньше по порядку есть свободная). When перетаскивание ручки на крае, Then размер меняется с привязкой к ячейкам, накрытые виджеты переезжают или сжимаются до ячейки; без места изменение не применяется. Ручки — акцентные полоски на непрозрачной подложке. Given TalkBack, Then у виджета есть действия «Переместить раньше/позже», «Увеличить» и «Уменьшить». When сетка полна, Then добавление недоступно. Нет горизонтального скролла и свободного масштабирования (ADR-0040).
- **AC-39.3.** When добавление, Then выбор содержит только маленькие виджеты, подходящие ячейке с учётом минимального размера и системных полей. When выбор экземпляра, Then штатная привязка и при необходимости конфигурация. Given отмена/ошибка, Then id освобождён. Вне редактирования касания получает провайдер.
- **AC-39.4.** Given перезапуск или смена спейса, Then положение и размер каждого виджета восстановлены независимо для каждого спейса. Given хранилище v1–v3, Then виджеты разложены по ячейкам в прежнем порядке строка за строкой (стандартная колонка остаётся колонкой), часы v1/v2 — первая ячейка, скрытые часы убраны. Если записей больше четырёх, сначала убираются часы, затем отбрасываются виджеты сверх четырёх, их id освобождены. When удаление виджета, приложения или спейса, Then соответствующие экземпляры освобождены.
