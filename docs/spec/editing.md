# Редактирование главного экрана и визуальный отклик

Актуализация по [ADR-0037](../adr/0037-edit-controls-widgets-and-touch-feedback.md), 2026-11-07. Предыдущие правила действуют в части, не заменённой этим ADR. Панель виджетов заменена по [ADR-0039](../adr/0039-compact-top-widget-panel.md).

- **AC-37.1.** Given режим редактирования, When пользователь нажимает приложение или папку, Then открывается минимодалка: название, «Убрать из списка», «Заменить» в указанном порядке. В самой строке кнопок редактирования и удаления нет. У приложения «Заменить» сохраняет место строки и открывает выбор замены; у папки открывает её редактор. Удаление папки не удаляет приложения с устройства.
- **AC-37.2.** Given режим редактирования, When пользователь нажимает нижнюю кнопку «?», Then поверх главного экрана открывается минимодалка советов с разделами «Список приложений и папки», «Виджеты», «Шрифт», «Тема». When Back, Then минимодалка закрывается, режим редактирования остаётся. Вне режима кнопки советов редактирования нет.
- **AC-37.3.** Given активная кнопка или кнопка-иконка, When нажатие в произвольной точке, Then из этой точки распространяется обрезанный границами элемента радиальный градиент, который исчезает при отпускании. Каждый переход ≤ 200 мс. Масштабирования и выбора прежних пяти стилей нет.
- **AC-37.4.** Given любая фиксированная тема и произвольное изображение фона, Then кнопки-иконки имеют непрозрачные подложки из темы. Контраст значка к подложке ≥ 3:1. Активное редактирование обозначено акцентной скруглённой квадратной кнопкой. Список тем не меняется.
- **AC-37.6.** Given «Ввод жестами» выключен, Then подчинённые настройки остаются видимыми и приглушёнными, их действия и accessibility-действия недоступны. Переключатель находится справа от названия секции. When включение, Then действия доступны с сохранёнными значениями.
- **AC-37.7.** Given минимодалка добавления жеста, Then между подсказкой и клавиатурой фиксированный небольшой отступ, а высота определяется содержимым и доступным экраном, без растягивания до 70% экрана.
- **AC-37.8.** Given рисование жеста на главном экране или клавиатуре, Then след — непрерывный сглаженный силуэт; за 200 мс старые точки теряют толщину и исчезают, без цепочки кругов на стыках. Распознавание получает исходные координаты и время независимо от визуального следа.

- **AC-39.1.** Given главный экран, Then панель виджетов только сверху; встроенные часы — обычная ячейка панели (по умолчанию первая) и входят в её лимит. Given редактирование, Then на часах кнопка «Настроить» по центру (минимодалка «Часы»: формат, размер, дата) и «Убрать» в углу, на остальных ячейках — «Убрать»; содержимое ячейки центрировано; часы переносятся как любой виджет. Given часы убраны, Then они доступны первым пунктом выбора виджета, выбор открывает минимодалку «Часы». Given пустая панель, Then вне редактирования она не занимает места, в редактировании есть ячейка добавления.
- **AC-39.2.** Given стандартная панель, Then доступны один или два маленьких виджета в ряд либо колонку. Given расширенная панель, Then доступно до четырёх в сетке 2×2. Нет горизонтального скролла или свободного масштабирования. When панель полна, Then добавление недоступно. When виджетов больше двух, Then переход в стандартную панель недоступен с объяснением.
- **AC-39.3.** When добавление, Then выбор содержит только маленькие виджеты, подходящие ячейке с учётом минимального размера и системных полей. When выбор экземпляра, Then штатная привязка и при необходимости конфигурация. Given отмена/ошибка, Then id освобождён. Given редактирование, When удержание и перенос в соседнюю ячейку, Then порядок изменён; вне редактирования касания получает провайдер.
- **AC-39.4.** Given перезапуск или смена спейса, Then режим, ориентация и порядок восстановлены независимо для каждого спейса. Given хранилище v1/v2, Then экземпляры сохранены, нижние перенесены наверх, часы стали первой ячейкой (при переполнении стандартной панели выбирается расширенная), скрытые часы убраны из панелей, лишние остаются в управлении без удаления id. When удаление виджета, приложения или спейса, Then соответствующие экземпляры освобождены.
