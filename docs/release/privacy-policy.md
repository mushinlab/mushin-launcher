## Русский

**Какие данные собираются.** Никакие. У Энва нет разрешения на доступ к интернету, поэтому он технически не может отправить данные с устройства. В приложении нет рекламы, аналитики, отчётов о сбоях и сторонних SDK, которые передают данные.

**Что хранится на устройстве:**
- Энвы, порядок приложений в них, переименования и скрытые приложения.
- Настройки.
- История запусков из поиска: время и число запусков. Используется только для сортировки результатов.
- Выученные жесты: последовательности букв нарисованных путей и приложение, к которому они относятся.

Эти данные хранятся только в личной папке приложения и не включаются в резервные копии и перенос на другое устройство. Они удаляются при удалении Энва. Данные приложения можно удалить вручную: «Настройки → Приложения → Энв → Хранилище → Очистить хранилище».

**Список приложений.** Энв получает от системы список установленных приложений, у которых есть значок запуска. Список нужен, чтобы показывать приложения на главном экране и в поиске. Он никуда не передаётся.

**Уведомления.** Счётчик уведомлений выключен по умолчанию. Если его включить и выдать доступ в системных настройках, Энв видит только, сколько уведомлений есть у каждого приложения. Текст, заголовки и вложения уведомлений не читаются и не сохраняются. Числа живут только в памяти, пока лаунчер работает. Доступ можно отозвать в любой момент: «Настройки → Уведомления → Доступ к уведомлениям».

**Дети.** Энв не предназначен для детей до 13 лет и не собирает данные ни о ком.

**Изменения.** Новая версия политики публикуется по этому же адресу с новой датой вступления в силу.

## English

**Data collected.** None. Env does not have the internet permission, so it technically cannot send data off your device. The app contains no ads, no analytics, no crash reporting and no third-party SDKs that transmit data.

**Stored on your device:**
- Envs, the order of apps in them, renamed and hidden apps.
- Settings.
- Search launch history: the time and number of launches. It is used only to rank search results.
- Learned gestures: the letter sequences of drawn paths and the app each one belongs to.

This data is kept only in the app's private storage. It is excluded from backups and device-to-device transfer, and it is deleted when you uninstall Env. You can also delete it manually in Settings → Apps → Env → Storage → Clear storage.

**App list.** Env reads the list of installed apps that have a launcher icon from the system. It uses the list only to show those apps on the home screen and in search, and never transmits it.

**Notifications.** Notification counts are off by default. If you turn them on and grant access in system settings, Env sees only how many notifications each app has. Notification text, titles and attachments are never read or stored. The counts live only in memory while the launcher is running. You can revoke access at any time in Settings → Notifications → Notification access.

**Children.** Env is not directed at children under 13 and collects no data about anyone.

**Changes.** A new version of this policy is published at the same address with a new effective date.
