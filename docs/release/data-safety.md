# Ответы для Play Console

## Data safety («Безопасность данных»)
Сбором данных Google Play считает передачу данных с устройства. Данные, которые обрабатываются только на устройстве, к сбору не относятся.

| Вопрос | Ответ |
|---|---|
| Собирает ли приложение или передаёт третьим лицам какие-либо из перечисленных типов данных? | **Нет** |
| Шифрование при передаче | Не применимо: данные не передаются |
| Можно ли запросить удаление данных | Не применимо: аккаунтов нет, данные удаляются вместе с приложением |

## App content («Контент приложения»)
| Раздел | Ответ |
|---|---|
| Политика конфиденциальности | Публичный URL страницы из `privacy-policy.md` |
| Доступ к приложению | Все функции доступны без входа в аккаунт |
| Реклама | Нет рекламы |
| Возрастной рейтинг (анкета IARC) | Категория «Утилиты / продуктивность»; насилия, азартных игр, общения между пользователями, покупок и геолокации нет |
| Целевая аудитория | 18+ (или 13+). Не ниже 13: иначе действует политика Families |
| Новостное приложение | Нет |
| Финансовые функции, здоровье, госприложение | Нет |

## Разрешения, о которых может спросить ревью
| Разрешение | Зачем |
|---|---|
| `EXPAND_STATUS_BAR` | Открыть шторку уведомлений по свайпу, назначенному пользователем |
| `REQUEST_DELETE_PACKAGES` | Пункт «Удалить» в меню приложения. Система всегда показывает своё подтверждение |
| `BIND_NOTIFICATION_LISTENER_SERVICE` (защищает сервис, это не запрос разрешения) | Необязательный счётчик уведомлений. Доступ пользователь даёт сам в системных настройках; читается только количество |

Фон спейса из галереи выбирается системным Photo Picker: `READ_MEDIA_IMAGES` не запрашивается, снимки остаются на устройстве и в Data safety не указываются.

`QUERY_ALL_PACKAGES`, `INTERNET` и Accessibility API не используются. Видимость приложений обеспечивают `<queries>` с MAIN/LAUNCHER и `LauncherApps`.

## Риски ревью
- **Шторка уведомлений открывается скрытым методом `StatusBarManager.expandNotificationsPanel`** (рефлексия, ADR-0001 D.13). Это не нарушение политики, но pre-launch report может отметить non-SDK interface. Если вызов не сработает, остальные функции продолжают работать.
