# Публикация Mushin Launcher в Google Play

## Что уже готово в коде
- Release-сборка: R8 и сжатие ресурсов включены. Подписывается ключом загрузки из `keystore.properties` в корне проекта; файл в `.gitignore`, как и `*.jks` / `*.keystore`. Без этого файла release собирается неподписанным; debug-подпись для проверок на эмуляторе — только явно: `-Pmushin.debugSignedRelease=true`. Play такой бандл не примет.
- Значок приложения: адаптивный, с монохромным слоем для тематических значков. В Play — `assets/icon-512.png`, обложка — `assets/feature-graphic-1024x500.png`.
- Вход `MAIN` + `INFO`. Кнопка «Открыть» в Google Play запускает Mushin Launcher: он открывается, когда задан лаунчером по умолчанию, иначе предлагает им стать. При этом лаунчер не появляется в списке приложений — ни в своём, ни в чужих лаунчерах (ADR-0006).
- Текст политики конфиденциальности в приложении («Настройки → Система → Конфиденциальность») — это требование Play для всех приложений.
- Тексты карточки — `store-listing.md`, скриншоты — `assets/screenshots/` (en, 1080 × 2160). Ответы на анкеты Play Console — `data-safety.md`. Политика для публикации на сайте — `privacy-policy.md`.
- Ревью безопасности и исправления — `security-review.md`. Защита от копирования, патенты и маркетинг — `protection-and-marketing.md`. Задача `./gradlew :app:checkReleasePermissions` падает, если в release-манифест попали `INTERNET` или `QUERY_ALL_PACKAGES`.

## Первый шаг: аккаунт разработчика
Зарегистрируйтесь в Play Console: https://play.google.com/console/signup.
- **Тип аккаунта** — личный или организация. Для организации нужен номер D-U-N-S, зато у неё нет обязательного закрытого теста (см. шаг 5).
- **Взнос** — $25 один раз и проверка личности по документу.
- **Если регистрация или оплата недоступны в вашей стране**, есть альтернативы: RuStore; F-Droid (порядок подачи — `f-droid.md`); раздача APK напрямую.

Проверка аккаунта занимает от нескольких дней. За это время можно сделать шаги 2–3.

## Шаги дальше
1. **Ключ загрузки.** Создайте его сами — пароль вводите только вы, никому не передавайте:
   ```bash
   keytool -genkeypair -v -keystore ~/keys/mushin-upload.jks -alias upload -keyalg RSA -keysize 4096 -validity 10000
   ```
   Затем в корне проекта создайте `keystore.properties` (в git он не попадёт):
   ```properties
   storeFile=/Users/<вы>/keys/mushin-upload.jks
   storePassword=<пароль хранилища>
   keyAlias=upload
   keyPassword=<пароль ключа>
   ```
   Сохраните `.jks` и пароли в надёжном месте вне компьютера. Если ключ загрузки потеряется, Play может его сбросить. Сам ключ подписи приложения хранит Google (Play App Signing).
2. **Сборка:** `./gradlew :app:bundleRelease` → `app/build/outputs/bundle/release/app-release.aab`. Перед этим прогоните полный набор проверок из `AGENTS.md`.
3. **Политика конфиденциальности по публичному адресу.** Заполните дату и контакт в `privacy-policy.md` и опубликуйте страницу: GitHub Pages, Google Sites или свой сайт. Этот шаг отправляет текст в сеть — делаете вы.
4. **Play Console → «Создать приложение».**
   - Язык по умолчанию — русский, тип — приложение, бесплатно.
   - Заполните разделы «Контент приложения» и «Безопасность данных» по `data-safety.md`.
   - Карточка — из `store-listing.md` и `assets/`, плюс не меньше двух скриншотов.
5. **Закрытое тестирование.** Нужно, если аккаунт личный и создан после 13.11.2023. Добавьте трек closed testing, загрузите `.aab` и тестировщиков (список e-mail или Google Group). Требование Play — **не меньше 12 тестировщиков, подключённых непрерывно 14 дней**. После этого — «Подать заявку на доступ к продакшну».
6. **Продакшн:** выпуск, ревью Google — обычно от нескольких часов до нескольких дней.

## Что решить владельцу
- Q-71: публичный контактный e-mail для политики и карточки (отложено).
- Q-77: `profileable` в release.
- Q-78: «спейс» или «пространство» в русском интерфейсе.
- Q-79: менять ли `applicationId` до первой публикации.
- Товарный знак «Mushin»: проверить в WIPO Global Brand Database (branddb.wipo.int), EUIPO TMview (tmdn.org/tmview), USPTO (tmsearch.uspto.gov) и, если нужна Россия, в ФИПС (fips.ru). В Google Play приложения «Mushin Launcher» на 2026-10-04 нет. Слово «Mushin» используют Mushin Mind (медитации), MUSHIN.FM и другие.

## Верификация разработчиков Android
С 30.09.2026 в Бразилии, Индонезии, Сингапуре и Таиланде, а в 2027 году по всему миру на сертифицированных устройствах будут устанавливаться только приложения проверенных разработчиков. Для приложений в Google Play регистрация проходит автоматически через Play Console. Это важно, если вы захотите раздавать APK вне Play: тогда нужен Android Developer Console (https://developer.android.com/developer-verification).
