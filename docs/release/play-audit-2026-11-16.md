# Аудит перед подачей в Google Play

Дата: 2026-11-16, исходный коммит a9bb7d5 (Release 0.10.0) с незакоммиченными правками после релиза. Прошлые аудиты: [2026-10-15](security-audit-2026-10-15.md), [2026-10-18](security-audit-2026-10-18.md), [2026-10-25](security-audit-2026-10-25.md).

Проверка глазами ревьюера Google Play: политики, анкеты, карточка, технические требования. Проверялись выпущенный APK 0.10.0, release-бандл и отладочная сборка на эмуляторе API 36.

## Итог
Причин для отказа по политикам в коде нет. Заявку в прежнем виде вернули бы из-за карточки: описание обещало удалённую функцию, скриншоты устарели и не проходили по формату. Это исправлено, как и язык в сборке для Play и текст политики (ADR-0048). Четыре вопроса ждут владельца: ключ подписи, значок в списке приложений, права на рисунки, прогон на Android 17.

## Находки и решения

| # | Находка | Серьёзность | Решение |
|---|---|---|---|
| P1 | Описание обещало «пять стилей отклика на нажатие» (выбор удалён в ADR-0037, `PressFeedback` — наследие), «иконки слева» (в коде только справа или без) и стирание всех данных одним нажатием (стираются история запусков и жесты) | High: вводящие в заблуждение метаданные | **Исправлено** в `fastlane/metadata/android/{en-US,ru-RU}/full_description.txt` и `store-listing.md` |
| P2 | Скриншоты показывали старый интерфейс: выбор «Press animation», главный экран без нижней панели. Набор fastlane 1080×2400 не проходит ограничение Play: длинная сторона больше двух коротких | High | **Исправлено.** Шесть кадров 1080×2160 в `assets/screenshots/` и `fastlane/.../phoneScreenshots/` |
| P3 | Обложка 1024×500 сохранена с альфа-каналом, Play требует PNG без него | Low | **Исправлено.** Альфа была полностью непрозрачной, картинка не изменилась |
| P4 | Политика, текст в приложении и `data-safety.md` не упоминали, что с 0.10.0 лаунчер видит приложения с виджетами (`<queries>` с `APPWIDGET_UPDATE`, ADR-0044). В файле политики был абзац-инструкция для разработчика | Medium | **Исправлено.** Политика датирована 2026-11-16, `system_privacy_text` обновлён на семи языках |
| P5 | Бандл резал ресурсы по языкам, а язык выбирается в приложении через `LocaleManager` (`AppLanguage.kt`). Из Play пришли бы только языки системы; выбранный язык появился бы после докачки самим Play, без сети — никогда | High для сборки из Play | **Исправлено.** `bundle.language.enableSplit = false`; в `BundleConfig.pb` разрезание по языкам отключено. На устройстве из Play не воспроизводилось |
| P6 | Ключ подписи выбирается один раз. Бандл подписывается ключом релизов GitHub (`50:54:7D…0F:87:29`). Шаг 1 в `README.md` советует отдельный ключ загрузки и ключ подписи у Google, ADR-0014 п. 4 — загрузить существующий. Если ключ создаст Google, сборки из Play и с GitHub не обновятся друг поверх друга, а переустановка сотрёт данные: резервные копии выключены | High | **Вопрос владельцу**, Q-180 |
| P7 | Нет активности с категорией `LAUNCHER` (ADR-0006). `monkey -c android.intent.category.LAUNCHER` отвечает «No activities found to run»; категория `INFO` находит `MainActivity`, поэтому кнопка «Открыть» в Play работает. Отчёт перед запуском может оказаться пустым, проверяющий может не найти приложение | Medium | В `data-safety.md` добавлен текст для поля «Доступ к приложению». Нужна ли активность `LAUNCHER` — **вопрос владельцу**, Q-181 |
| P8 | Цель — API 37, а тесты идут на API 36: локальный эмулятор, CI (`api-level: 36`), образа API 37 на машине нет. На Android 17 для всех приложений действуют лимиты памяти | Medium | **Вопрос владельцу**, Q-183 |
| P9 | Происхождение пяти встроенных рисунков тушью не записано: в ADR-0032 только «прислал владелец». Политика об интеллектуальной собственности требует прав на них | Medium | **Вопрос владельцу**, Q-182 |
| P10 | Шторка уведомлений открывается скрытым методом. Лог эмулятора: `StatusBarManager;->expandNotificationsPanel()V (… api=unsupported,test-api)` | Low | Принято как есть (D.13). Сейчас вызов разрешён, отчёт Play покажет предупреждение; на случай отказа есть сообщение `notice_shade_unavailable` |
| P11 | Личный аккаунт разработчика: закрытый тест, 12 тестировщиков 14 дней подряд, до заявки на продакшн. В карточке личного аккаунта показываются настоящее имя и страна — проверить при регистрации | Info | Организационное; закрытый тест описан в `README.md`, шаг 5 |
| P12 | В `fastlane/metadata/android/*/changelogs/` нет файлов для versionCode 12–15 | Info | Не исправлено: текст «Что нового» вводится при выпуске |
| P13 | Строки `settings_press` и `press_*` остались в ресурсах семи языков, код их не использует | Info | Не тронуто: вне задачи аудита |

## Проверено, нарушений нет
- **Разрешения.** В выпущенном APK только `EXPAND_STATUS_BAR` и `REQUEST_DELETE_PACKAGES`, оба обычные. Нет `INTERNET`, `QUERY_ALL_PACKAGES`, службы специальных возможностей, администратора устройства, фоновых служб и точных будильников.
- **Сеть и данные.** В коде нет сетевых вызовов, WebView, ссылок, загрузки кода, сторонних SDK и самообновления. Ответ «данные не собираются» в анкете соответствует коду.
- **Уведомления.** `NotificationCountService` читает пакет, профиль, признак «можно смахнуть» и признак сводки группы. Служба выключена по умолчанию, пояснение показывается до выдачи доступа.
- **Системные действия.** Удаление приложения, роль лаунчера, выбор фото и привязка виджета идут через системные диалоги и только по действию пользователя.
- **Компоненты.** Экспортированные службы закрыты системными разрешениями; резервные копии и перенос данных выключены; секретов в истории git нет.
- **Технические требования.** Требование Play — API 36 с 31 августа 2026, цель приложения — 37. Все восемь нативных библиотек выровнены под страницы 16 КБ. `.aab` собирается (5,2 МБ) и подписан.
- **Большой экран.** При цели API 36 и выше портретная блокировка на экранах от 600dp не действует. На экране 1600×2560 в альбомной ориентации главный экран, поиск и настройки работают без падений; вёрстка растянута.
- **Доступность.** Кнопки-иконки 48dp с описаниями; шрифты под лицензией OFL, тексты лицензий лежат в APK.

## Что не проверено
- Загрузка в Play Console и её отчёт перед запуском.
- Установка из бандла через Play, в том числе смена языка.
- Поведение на Android 17.
- Занятость названия «Mushin» как товарного знака.

## Проверено после исправлений
- Предкоммитная проверка: успешно.
- `:app:bundleRelease`: собирается, подписан, разрезание по языкам отключено.
- Скриншоты: шесть кадров 1080×2160 без альфа-канала; обложка 1024×500 без альфа-канала.
- UI-тесты не перезапускались: логика не менялась, текст политики тесты не читают.
