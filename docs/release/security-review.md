# Ревью безопасности перед публикацией

Дата: 2026-10-04, коммит bc8b771.

Ревью провели два независимых ревьюера на разных моделях (Opus и Sonnet). Каждый работал в своей копии репозитория без контекста разработки и с запретом на сеть, правки и устройства.

**Критичных находок нет.** Главное обещание держится у обоих: нет `INTERNET`, нет сетевого кода, нет `QUERY_ALL_PACKAGES`, нет секретов ни в дереве, ни в истории.

## Подробности по п. 3
- У `AppContainer.scope` есть `CoroutineExceptionHandler`: ошибка фоновой задачи пишется в лог и не убивает процесс.
- DataStore настроек создаётся с `ReplaceFileCorruptionHandler`: повреждённый файл заменяется настройками по умолчанию. Тест подкладывает мусор вместо файла.
- `IconLoader.render` при любой ошибке отрисовки чужого drawable отдаёт букву вместо иконки.
- Две записи настроек (смена энва и раскладки) перенесены из `viewModelScope` в `container.scope`, к остальным записям.

## Проверено ревьюерами и в порядке
- **Экспортированные компоненты.**
  - `MainActivity`: HOME/INFO, extras не читает, `taskAffinity=""` защищает от перехвата задачи.
  - Слушатель уведомлений защищён `BIND_NOTIFICATION_LISTENER_SERVICE`.
  - Провайдеров и PendingIntent нет; динамические приёмники `NOT_EXPORTED`.
- **Запуск приложений.** Через `LauncherApps` или явный компонент из каталога. Удаление идёт через системное подтверждение. `REQUEST_DELETE_PACKAGES` действительно нужен.
- **Уведомления.** Читаются только пакет, пользователь, флаги clearable и group summary. Счётчики живут в памяти.
- **Ввод.** Нет `TextField`, поэтому ввод не попадает в IME, автозаполнение и буфер обмена.
- **Хранение.**
  - Всё во внутреннем хранилище; запросы Room параметризованы.
  - Миграции без разрушения данных.
  - Повреждённые снимок и кэш иконок обрабатываются.
- **Сборка.**
  - R8 и сжатие ресурсов включены; не debuggable, не testOnly.
  - Репозитории только Google, Maven Central и Plugin Portal, плюс `FAIL_ON_PROJECT_REPOS`.
  - Дистрибутив Gradle закреплён по SHA-256.
