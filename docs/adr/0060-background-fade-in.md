# ADR-0060. Фон спейса проявляется за секунду

Статус: принято по указанию владельца, 2026-11-27.

## Контекст
При смене спейса фон появляется резко. Владелец просит плавное проявление примерно за секунду.

## Решения
1. **Проявление.** Когда у главного экрана меняется картинка фона — после смены спейса, когда картинка догрузилась, или когда фон поставили, — новая картинка проявляется поверх прежней за 1000 мс. Если у нового спейса фона нет, прежняя картинка так же уходит за 1000 мс. Это исключение из ограничения переходов 200 мс (ADR-0003) по прямому указанию владельца: меняется только фон, экран доступен сразу.
2. **Без двойного перехода.** Пока поверх лежит страница соседа (листание и смена спейса из popup со сдвигом или растворением), фон под ней меняется сразу: страница соседа уже показывает новый фон, и после её растворения старый фон не проступает. Обои соседа, которые догружаются во время листания, тоже проявляются за секунду, а не появляются рывком.
3. Новых зависимостей нет.

## Критерии приёмки
- **AC-60.1.** Given главный экран без фона, When фон появился, Then через два кадра фон почти не виден, через 1,2 с виден полностью.
