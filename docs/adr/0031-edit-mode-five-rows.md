# ADR-0031. В режиме редактирования видны пять строк списка

Статус: принято (указание владельца; трактовки агента помечены). 2026-10-24. Дополняет ADR-0028 п. 2.

## Контекст
Владелец: «В режиме edit сократи список элементов до 5 максимум, показывай его полностью только когда пользователь тянет за драгндроп этого списка».

## Решения
1. В режиме редактирования видны первые пять строк списка. Строка «Добавить приложения» считается строкой (трактовка агента).
2. Пока палец тянет линию над списком, видны все строки. После отпускания лишние снова скрываются.
3. Скрытые строки не убираются из раскладки, а становятся прозрачными. Переход занимает 200 мс (ADR-0003), поэтому список не прыгает, а вместимость экрана и подсказки «?» считаются как обычно (трактовка агента).
4. Скрытая строка «Добавить приложения» не нажимается.
5. Правило — чистая функция `EditList.shown` с unit-тестом.
