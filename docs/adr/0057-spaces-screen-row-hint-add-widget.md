# ADR-0057. Экран «Спейсы» в настройках, подсказка удаления на одной строке, кнопка «Добавить виджет» сверху, ряды клавиатуры одной высоты, высота списка при смене спейса

Статус: принято по указанию владельца, 2026-11-27. Меняет ADR-0055 (решение 5, Q-204), подсказку удаления строки из 0.10.1 и полоску спейсов в корне настроек.

## Контекст
Владелец после 0.13.0:
1. В конце переключения спейса список приложений меняет высоту с анимацией, мелькает полоса прокрутки.
2. В настройках не осталось ничего, что относится к одному спейсу, поэтому переключатель спейсов сверху не нужен. Нужен отдельный пункт сверху с обычным списком: значки «переименовать» и «удалить» без удержания, редактируется только имя.
3. Подсказка удаления строки некрасивая: двигаются все строки и слишком резко. Нужна одна строка при нажатии на карандаш и движение около полутора секунд.
4. Четыре ряда клавиатуры должны быть одной высоты.
5. Кнопка «Добавить виджет» в одну мелкую клетку слишком маленькая; нужна кнопка сверху.

## Решения
1. **Высота списка.** Плавно меняется только переход в режим редактирования и обратно (5,5 строки и полный список). Новое число строк — после смены спейса, добавления или удаления — применяется сразу, без анимации высоты.
2. **Экран «Спейсы».** В корне настроек первым идёт пункт «Спейсы»; полоски спейсов сверху больше нет. На экране — строка на каждый спейс: имя, тип, значок «Переименовать» (диалог с именем) и значок «Удалить» (кроме обычного спейса, с системным подтверждением). Внизу — строка «Новый спейс» с тем же диалогом создания. Выбирать спейс в настройках больше нельзя, переключение — на главном экране.
3. **Подсказка удаления.** Только первая строка списка, при входе в режим редактирования: через 200 мс строка за 600 мс отъезжает на 56 dp, открывая значок удаления, стоит 300 мс и за 600 мс возвращается (всего 1,5 с, плавное замедление). Это исключение из ограничения переходов 200 мс (ADR-0003) по прямому указанию владельца: это подсказка, а не переход между экранами.
4. **Ряды клавиатуры.** Нижний ряд (кнопка размера и пробел) той же высоты, что ряды букв; клавиатура стала выше на половину ряда.
5. **«Добавить виджет».** В режиме редактирования кнопка-таблетка со значком виджетов и текстом «Добавить виджет» стоит в свободной полосе над виджетами (40 dp, раскладка не сдвигается). Нажатие добавляет виджет в то же место, что и раньше: первая свободная четверть, без неё — первая свободная мелкая клетка. Кнопок внутри сетки больше нет. При заполненной сетке кнопки нет.
6. Новых зависимостей, разрешений и изменений схемы нет.

## Вопросы, решённые без владельца
| № | Вопрос | Решение |
|---|---|---|
| Q-210 | Оставить выбор текущего спейса на экране «Спейсы»? | Нет: в настройках нет настроек отдельного спейса, переключение — на главном экране |
| Q-211 | Какая строка показывает подсказку удаления? | Первая строка списка |
| Q-212 | Кнопка сверху вместо кнопок в сетке или вместе с ними? | Вместо: кнопка добавления одна, как в ADR-0055 |

## Критерии приёмки
- **AC-57.1.** Given настройки, When открыть корень, Then первым идёт пункт «Спейсы», полоски спейсов нет; на экране «Спейсы» у каждого спейса значки «Переименовать» и «Удалить» (у обычного — только «Переименовать»), строка «Новый спейс» создаёт спейс.
- **AC-57.2.** Given спейс с 3 строками, When переключиться на спейс с 1 строкой, Then через два кадра высота списка уже равна одной строке.
- **AC-57.3.** Given главный экран, When нажать карандаш, Then отъезжает только первая строка и через 1,5 с возвращается.
- **AC-57.4.** Given поиск, Then пробел и кнопка размера той же высоты, что клавиши букв.
- **AC-57.5.** Given режим редактирования и свободное место, Then над виджетами кнопка «Добавить виджет», в сетке кнопок добавления нет; при заполненной сетке кнопки нет.
