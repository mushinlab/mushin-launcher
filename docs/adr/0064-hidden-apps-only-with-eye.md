# ADR-0064. Скрытые приложения в поиске — только при включённом глазе

Статус: принято по указанию владельца, 2026-11-28. Меняет AC-09.4.

## Контекст
По AC-09.4 скрытое приложение находилось по точному совпадению или началу названия и помечалось «(скрыто)»: набрав «kee», владелец увидел «Keep Notes (hidden)». Владелец: функция скрытия не работает — скрытое не должно появляться.

## Решения
1. Скрытые приложения не попадают в результаты поиска ни при каком совпадении, пока в шапке поиска не включён глаз «Показать скрытые» (AC-45.2). С включённым глазом они ищутся как обычные, с суффиксом «(скрыто)».
2. Пустой запрос, недавние, словарь рисунков на клавиатуре — без изменений: скрытые там и раньше не показывались без глаза.
3. AC-09.4 в `docs/spec/functional.md` и правило в `docs/spec/tech.md` обновлены. Новых зависимостей и разрешений нет.

## Критерии приёмки
- **AC-64.1.** Given скрытое «Slack», When запрос «slack», «sla» или «слак» без глаза, Then результатов нет; When глаз включён, Then «слак» находит Slack как EXACT.
