# ADR-0021. Никаких иконок без подложки

Статус: принято (указание владельца). 2026-10-17.

## Контекст
Карандаш на главном экране терялся на светлой части картинки-фона: иконка рисовалась прямо поверх фона, без подложки.

## Решения
1. **Каждая кнопка-иконка стоит на круглой подложке.** `GlyphButton` (`core:ui`) всегда рисует круг цвета поверхности палитры (`surface`) с обводкой 1 dp цвета `PopupStyle.outline`, как у всплывающих панелей. Отклик на нажатие — по кругу. Область касания остаётся 48 dp. Отключить подложку параметром нельзя: так новая кнопка не появится без неё.
2. **Линия перетаскивания списка** тоже стоит на подложке: капсуле цвета поверхности с той же обводкой.
3. **Правило для нового кода** (AGENTS.md, «Стиль»): иконки и элементы управления поверх фона или картинки рисуются только на подложке. Кнопки-иконки — только через `GlyphButton`. Маленькие значки внутри строк (стрелки свайпов, счётчик) допустимы без своей подложки: у строк подложка есть (ADR-0020).
