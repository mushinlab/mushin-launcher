# ADR-0054. Одна тема на все спейсы, листание за пальцем, настраиваемая анимация смены спейса

Статус: принято по указанию владельца, 2026-11-22. Меняет ADR-0050 (слайд после отпускания → страницы за пальцем, решения 3–5 и 7), дополняет ADR-0053 (обучение приватного спейса, решение 6) и ADR-0049 (контраст часов).

## Контекст
Владелец после 0.11.0:
1. В минимодалке «Тема» нужен тоггл «одна тема на все».
2. Обучение приватного спейса — карточка с текстом; должно быть таким же красивым, как подсказки (Tips).
3. Свайп спейсов плохой: страница должна ехать за пальцем, а сзади — размытое превью, чтобы не считать всё сразу.
4. Время мигает при смене спейса.
5. Анимация смены спейса, кроме свайпа, должна настраиваться; в режиме редактирования — иконка «motion».

## Решения
1. **Одна тема на все.** В минимодалке «Тема» под палитрой — тоггл «Одна тема на все спейсы» (`shared_theme` в DataStore). Включение копирует палитру и «Цветные иконки» текущего спейса во все спейсы, кроме приватного. Пока тоггл включён, смена палитры или цветных иконок в любом месте (минимодалка, настройки спейса) применяется ко всем, новый спейс сразу получает общую тему. Заголовок минимодалки — «Тема всех спейсов». Выключение ничего не откатывает: дальше спейсы снова меняются по одному. Приватный спейс сохраняет палитру `Night` (ADR-0053).
2. **Листание за пальцем.** Горизонтальный жест по нижней плашке (направление по первому выходу за touch slop: |dx| > |dy|) двигает страницу текущего спейса за пальцем. С края въезжает превью соседнего спейса: цвет фона палитры, уменьшенная копия обоев (≈360 px по длинной стороне) и полосы строк зебры, всё размыто на `BackgroundLook.BLUR_MAX`; имя спейса на месте нижней плашки — чёткое. Превью соседей готовятся заранее в фоне при смене спейса и обоев; полный экран соседа не строится.
3. Отпускание: если по порогам свайпа (96dp или бросок от 48dp при 1000dp/с) получилось LEFT/RIGHT в сторону сдвига — страница доезжает за оставшуюся долю 200 мс, иначе возвращается за 200 мс. После доезда превью закрывает экран, переключается спейс, лаунчер ждёт, пока на экране окажутся строки и обои нового спейса, и превью растворяется за 100 мс. Пока идёт анимация, жесты главного экрана молчат.
4. Свайп по кругу, пропуск приватного и молчание жеста внутри приватного и в режиме редактирования — как в ADR-0050/0053. Если соседа нет (один спейс), страница не двигается. Кнопка редактирования едет вместе со страницей.
5. **Часы не мигают.** Главный экран больше не пересоздаётся после листания: одна и та же страница живёт до и после смены спейса. Цвет часов в режиме «авто» при первом измерении и при смене фона или палитры ставится сразу, без анимации; плавный переход остаётся для движения часов и смены режима цвета.
6. **Анимация смены спейса.** В режиме редактирования на нижней плашке после «Темы» — кнопка `Glyph.MOTION`, она открывает минимодалку «Анимация» с выбором «Смена спейса»: «Сдвиг» (по умолчанию, превью въезжает сбоку за 200 мс), «Растворение» (превью проявляется поверх за 200 мс) или «Без анимации». Настройка `space_transition` действует на выбор спейса в popup; листание по плашке всегда идёт за пальцем. Из приватного спейса переключение по-прежнему без анимации (ADR-0053, решение 5), из настроек — тоже без анимации.
7. **Обучение приватного спейса.** Полноэкранная страница в стиле онбординга: мини-анимация (тап по плашке → popup → свайп вверх по нему → ввод PIN → приватный спейс в палитре `Night`), заголовок, текст, галочка «Я знаю, как пользоваться приватным спейсом» и кнопка «Продолжить», неактивная без галочки. Флаг `private_hint_seen` и правила показа — из ADR-0053.
8. Мини-плашка редактирования в подсказках рисует четвёртую кнопку «Анимация».
9. Новых зависимостей, разрешений и сетевых запросов нет. Схема БД не меняется.

## Вопросы, решённые без владельца
| № | Вопрос | Решение |
|---|---|---|
| Q-196 | Что входит в «тему»? | Палитра и «Цветные иконки» — то, что есть в минимодалке «Тема» на уровне спейса. Иконки вкл/выкл и счётчики уведомлений и так общие |
| Q-197 | Что делать при выключении «одной темы»? | Ничего не откатывать: у всех остаётся общая тема, дальше они меняются по одному |
| Q-198 | Что значит «анимация перехода кроме свайпа»? | Анимация смены спейса из popup. Переходы поиска, запуска приложений и минимодалок не трогаем |
| Q-199 | Какие варианты анимации? | Сдвиг, растворение, без анимации. Больше вариантов не добавляем без запроса |
| Q-200 | Что показывать на размытом превью? | Фон палитры, уменьшенные обои, полосы строк зебры и чёткое имя спейса. Часы и виджеты не рисуем |
| Q-201 | Должна ли кнопка редактирования оставаться на месте при листании? | Нет: она часть страницы, а на превью её нет — так проще и честнее показывает, что страница уезжает |

## Проверки
- **AC-54.1.** Given минимодалка «Тема», When включить «Одна тема на все спейсы» и выбрать палитру, Then она у всех спейсов, кроме приватного; новые спейсы получают её же.
- **AC-54.2.** Given больше одного спейса, When вести палец по нижней плашке, Then страница едет за пальцем, а с края виден размытый сосед с его именем; короткое отпускание возвращает страницу, спейс не меняется; длинное или быстрое — переключает.
- **AC-54.3.** Given режим редактирования, When кнопка «Анимация», Then открывается минимодалка с выбором «Сдвиг / Растворение / Без анимации»; с «Без анимации» выбор в popup переключает спейс без превью.
- **AC-54.4.** Given смена спейса любым способом, Then цвет часов не мигает: он ставится сразу под новый фон.
- **AC-54.5.** Given первый запуск после онбординга, Then обучение приватного спейса показано на весь экран с анимацией; «Продолжить» работает только с галочкой.

Unit: `shareTheme` (копирует палитру и цветные иконки во все неприватные спейсы, из приватного — ничего), сохранение `shared_theme` и `space_transition`, кодек маршрута `MotionSheet`. UI API 36: тоггл общей темы, превью при ведении по плашке и возврат при коротком отпускании, кнопка «Анимация», выбор в popup без анимации; существующие тесты листания и обучения приватного спейса. Плавность и вид превью — вручную на эмуляторе.
