# ADR-0022. Значки по умолчанию: слева и цветные

Статус: принято (указание владельца). 2026-10-17. Меняет AC-04.1 (`icon_mode` по умолчанию NONE) и ADR-0007, п. 10 (цветные значки по умолчанию выключены).

## Решения
1. **«Главный экран → Значки» по умолчанию — «Слева»:** `LauncherSettings.iconMode = LEFT`. Ключ DataStore `icon_mode` не меняется. Если значение уже сохранено, оно остаётся.
2. **«Стиль → Цветные значки» по умолчанию включены.** Это настройка спейса. Спейсы, создаваемые при первом запуске («Обычный», «Рабочий»), и новые спейсы получают `colored_icons = 1`. Значение задаётся при вставке строки, поэтому значение по умолчанию у колонки и схема БД не меняются, миграции нет.
3. **Уже установленные копии не меняются:** у них значение режима значков сохранено, а спейсы уже созданы. Новые значения по умолчанию действуют для новых установок и новых спейсов.
4. **UI-тесты** по-прежнему начинают со значков «Нет» и монохромных значков (`LauncherUiTestBase`): они проверяют раскладку списка и цвета без значков.
