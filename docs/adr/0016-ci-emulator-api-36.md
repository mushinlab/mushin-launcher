# ADR-0016. Ночные UI-тесты в CI — на эмуляторе API 36

Статус: принято агентом, ждёт подтверждения владельца. 2026-10-16.

## Контекст
Spec (`docs/spec/tech.md`, раздел CI) требует запускать instrumented-тесты по ночам на эмуляторе API 37. На раннерах GitHub (`ubuntu-latest`) нет пакета `platforms;android-37` и образа системы для него: ночной прогон 2026-10-16 упал до старта эмулятора (`Failed to find package 'platforms;android-37'`, adb не смог подключиться).

## Решение
Ночное задание `instrumented` запускает эмулятор API 36 (`google_apis`, x86_64). Локально все UI-тесты проходят на эмуляторе API 36, так же сказано в AGENTS.md. Сборка по-прежнему `compileSdk`/`targetSdk` 37.

## Когда вернуться
Когда у раннеров GitHub появится образ API 37 — вернуть `api-level: 37`.
