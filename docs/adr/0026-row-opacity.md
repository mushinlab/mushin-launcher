# ADR-0026. Прозрачность подложек строк в редакторе фона

Статус: принято (указание владельца; трактовки агента помечены). 2026-10-18. Дополняет ADR-0020.

## Контекст
С плотностью подложек 90 % (ADR-0020, п. 1) светлая картинка-фон и тёмные строки палитры выглядят слишком контрастно.

## Решения
1. В редакторе фона третий ползунок — «Подложка строк» / «Row background» — плотность подложек строк главного экрана поверх картинки. Это настройка спейса, как яркость и размытие.
2. Диапазон 20–100 %, по умолчанию 90 %: так строки выглядят как раньше. Ниже 20 % ползунок не опускается (трактовка агента): владелец просил, чтобы у строк всегда была подложка (ADR-0020).
3. Хранение: колонка `environment.bg_row_alpha REAL NOT NULL DEFAULT 0.9`, БД v10, автоматическая миграция v9→v10.
4. Значение действует на все строки списка главного экрана, включая «Добавить приложения», только когда у спейса есть картинка. Предпросмотр в редакторе показывает изменение сразу. «Убрать фон» сбрасывает значение на 90 %.
