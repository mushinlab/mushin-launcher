# ADR-0056. Подъём клавиатуры в режиме изменения размера

Статус: принято по указанию владельца, 2026-11-27. Дополняет решение о ширине и сдвиге клавиатуры (кнопка изменения размера и якоря по бокам).

## Контекст
Владелец хочет поднимать клавиатуру поиска выше, не растягивая её: список результатов становится ниже, под клавиатурой остаётся пустое место.

## Решения
1. **Жест.** В режиме изменения размера клавиатуру можно тянуть за любое место, кроме боковых якорей. Движение по вертикали больше порога касания (`viewConfiguration.touchSlop`) поднимает или опускает всю панель ввода, размер панели не меняется. Касание без движения, как и раньше, выходит из режима. Боковые якоря по-прежнему меняют ширину.
2. **Подсказка.** Сверху по центру рамки — горизонтальный якорь, как боковые; при захвате он выделяется так же.
3. **Пустое место.** Под панелью ввода появляется отступ высотой подъёма с фоном экрана; список результатов сжимается на ту же высоту. Свайп вниз по пустому месту закрывает поиск, как и по остальному экрану.
4. **Границы.** От 0 до 480 dp и не выше, чем позволяет список: у списка остаётся не меньше двух строк результатов (112 dp).
5. **Хранение.** Подъём — новая настройка `keyboardLift` в dp (ключ DataStore `kb_lift`, по умолчанию 0), сохраняется при отпускании пальца. Тот же подъём у клавиатуры в выборе приложений.
6. Новых зависимостей и разрешений нет.

## Вопросы, решённые без владельца
| № | Вопрос | Решение |
|---|---|---|
| Q-207 | Хватать за любое место или только за отдельный якорь? | За любое место, кроме боковых якорей: так проще попасть; верхний якорь — только подсказка |
| Q-208 | Подъём в dp или долей экрана? | В dp, как отступ списка на главном экране |
| Q-209 | Поднимать и клавиатуру выбора приложений? | Да, клавиатура везде стоит в одном месте |

## Критерии приёмки
- **AC-56.1.** Given режим изменения размера, When тянуть клавиатуру вверх за середину на 200 px, Then панель ввода поднимается на 200 px без изменения высоты, список становится на 200 px ниже, подъём сохранён, режим не закрылся.
- **AC-56.2.** Given перетаскивание, When тянуть дальше границ, Then подъём остаётся между 0 и местом, при котором у списка остаются две строки, и не больше 480 dp.
