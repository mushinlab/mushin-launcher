# ADR-0003. Правки владельца после первого запуска на Pixel 6

Статус: принято (указания владельца). Трактовки агента вынесены в «Открытые вопросы». 2026-10-03.

## Контекст
После установки на Pixel 6 владелец прислал 9 правок. Часть из них меняет spec: C.7 (клавиатура), C.8 (без анимаций), F6/F9 (popup, поиск), F10 (пикер). Правки владельца приоритетнее spec.

## Решения
1. **Enter.** Ряд с Enter на всю ширину из раскладок убран, клавиатура стала трёхрядной. «Открыть ⏎» — отдельная кнопка справа в строке запроса, прямо под панелью recents, шириной в треть экрана. Кнопка видна только в режиме набора.
2. **Свайп вниз закрывает поиск.** Работает на клавиатуре (≥ 72dp вниз, по вертикали больше, чем по горизонтали), на строке запроса и recents. На списке результатов поиск закрывается, когда список уже не может прокручиваться вниз (остаток nested scroll ≥ 72dp).
3. **Пикер приложений энва.** Каждый тап сразу добавляет или убирает приложение. Состояние «добавлено» показано фоном: accent с прозрачностью 24 %, переход 200 мс. Галочки нет. Нажатие вспыхивает фоном `keyPressed` и гаснет за 200 мс; это работает и для быстрых тапов в списках. Заголовок секции «Избранное» стал «Приложения» («Favorites» → «Apps»).
4. **Кнопка «Готово» убрана**: пикер применяет изменения сразу. Вместо неё показан счётчик «Выбрано N из M». Когда места нет, счётчик подсвечен accent, а невыбранные строки неактивны.
5. **Корень настроек.** Сверху отдельная секция «Энв «имя»» с одним пунктом «Приложения» (число приложений). Он ведёт на экран со списком приложений энва: порядок, удаление, «+ Добавить» → пикер. Общий пункт «Приложения» переименован в «Скрытые и переименованные», чтобы не было двух одинаковых пунктов.
6. **Направление анимации при запуске свайпом.** На Android 14+ система игнорирует `makeCustomAnimation`, `makeClipRevealAnimation` и `overridePendingTransition` для сторонних лаунчеров при запуске новой задачи. Это проверено на API 36 через `LauncherApps` и через прямой `startActivity`. Поэтому сам лаунчер за 200 мс сдвигает содержимое Home в сторону свайпа, а потом запускает приложение с `FLAG_ACTIVITY_NO_ANIMATION` (только основной профиль). Сдвиг сбрасывается в `onStop`. Приложения рабочего профиля запускаются через `LauncherApps` с системной анимацией.
7. **Ввод рисунком** — опция в «Клавиатура», по умолчанию выключена. Вместо клавиш показывается пустая панель того же размера. Путь пальца раскладывается на клавиши QWERTY по геометрии EN-раскладки, независимо от выбранной раскладки. Слово выбирается так: OSA-расстояние до «идеального» пути каждого слова из словаря плюс штрафы за несовпадение первой и последней буквы. Словарь — латинские слова и полные латинские имена видимых приложений, кириллица идёт через транслит. Распознанное слово заменяет запрос. Чистая логика — `GestureDecoder` в `:core:search`.
8. **Переходы по 200 мс.** Слой поиска появляется и скрывается за 200 мс (alpha и сдвиг на 24dp). Пока он гаснет, он перехватывает ввод, чтобы касание не попало в скрытую клавиатуру. Экраны настроек: push — новый экран въезжает справа, pop — уходит вправо. Открытие и закрытие настроек — fade. Popup, диалоги и подсказки показываются без анимации. Используется `androidx.compose.animation` (транзитивная зависимость foundation, новых зависимостей нет).
9. **Долгое нажатие на строке поиска** (результаты и recents) открывает меню под пальцем: «Добавить в энв» или «Убрать из энва», «О приложении», «Удалить». «Удалить» не показывается для системных приложений. После добавления или удаления сверху экрана появляется уведомление: «Добавлено в «энв»», «Убрано из «энв»» или «В «энв» больше не поместится».

## Изменения правил
- Запрет «НЕ анимации» в `AGENTS.md` заменён правилом: разрешены только переходы ≤ 200 мс из этого ADR и затухание нажатия. Ripple по-прежнему запрещён.
- Безопасность: агент не отправляет данные с компьютера в сеть. Разрешены только запросы без полезной нагрузки (скачивание зависимостей). Журнал решений на claude.ai больше не пополняется, новые вопросы записываются здесь.
