# ADR-0048. Подготовка к Google Play: языки в бандле, тексты карточки, политика, скриншоты

Статус: принято по указанию владельца, 2026-11-16. Дополняет ADR-0014 (публикация) и ADR-0044 (видимость приложений с виджетами).

## Контекст
Аудит перед подачей в Google Play (`docs/release/play-audit-2026-11-16.md`) нашёл четыре вещи, которые исправляются без решений владельца:
- описание в карточке обещает выбор из пяти стилей нажатия (удалён в ADR-0037), иконки слева (ADR-0028 оставил только справа) и стирание всех данных одним нажатием;
- скриншоты сняты 4 и 25 октября, до нынешнего интерфейса, а набор для fastlane (1080×2400) не проходит ограничение Play «длинная сторона не больше двух коротких»; обложка сохранена с альфа-каналом;
- политика и текст в приложении не упоминают, что с 0.10.0 лаунчер видит приложения с виджетами;
- App Bundle по умолчанию режет ресурсы по языкам, а язык интерфейса выбирается внутри приложения через `LocaleManager`. Из Play на устройство попадают только языки системы; остальные Play докачивает сам, когда есть сеть.

## Решения
1. **Языки в бандле не режутся:** `bundle.language.enableSplit = false` в `app/build.gradle.kts`. Все семь языков ставятся сразу, выбор языка работает без сети. APK с GitHub не меняется: в нём и так все языки.
2. **Карточка** (`fastlane/metadata/android/*/full_description.txt`, `docs/release/store-listing.md`): убраны пять стилей нажатия и иконки слева. Про «Конфиденциальность» сказано точно: экран показывает сохранённое и стирает историю запусков и выученные жесты.
3. **Политика** (`docs/release/privacy-policy.md`, дата 2026-11-16) и `system_privacy_text` на семи языках: добавлен список приложений с виджетами и самих виджетов. Из файла политики убран абзац-инструкция для разработчика; где смотреть и стирать данные — отдельным абзацем на обоих языках.
4. **Скриншоты** — один набор из шести кадров 1080×2160 для Play и fastlane: главный экран, поиск, ввод рисунком, встроенные фоны, тема, выбор спейса. Сняты на эмуляторе API 36 с экраном 1080×2160, без обрезки. Обложка пересохранена без альфа-канала.
5. **Анкеты Play** (`docs/release/data-safety.md`): запрос `APPWIDGET_UPDATE` и текст для поля «Доступ к приложению» — как открыть лаунчер без значка в списке приложений.

## Проверки
Предкоммитная проверка после правок строк и сборки. `:app:bundleRelease` собирается и подписывается; в `BundleConfig.pb` разрезание по языкам отключено (до правки список измерений был пуст, то есть действовало разрезание по умолчанию). Размеры шести скриншотов и обложки, отсутствие альфа-канала. UI-тесты не перезапускались: логика не менялась, текст политики тесты не читают. Установка из Play не проверялась.
