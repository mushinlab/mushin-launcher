# ADR-0069. Редизайн, этап 5: сегменты в минимодалках, плоские строки настроек

Статус: принято по указанию владельца, 2026-11-28.

## Контекст
Пятый этап редизайна из ADR-0065: минимодалки «Text», «Clock», «Motion», «Theme» на странице redesign холста. Выпадающий список ради трёх вариантов требует двух нажатий и прячет выбор; карточки под каждой строкой настроек делают экран пёстрым.

## Решения
1. **`SegmentedRow`**: заголовок строки, под ним во всю ширину сегменты с равной шириной на подложке `keyBackground`, выбранный — `keyPressed` и `textPrimary`, остальные — `textSecondary`. Один тап выбирает вариант. Теги вариантов прежние: `${tagPrefix}_${значение}`; тег строки — `${tagPrefix}_segments`.
2. Сегменты вместо выпадающих списков: «Насыщенность», «Размер текста», «Выравнивание текста» в «Тексте»; «Размер часов», «Формат часов», «Цвет шрифта» в «Часах»; «Смена спейса» в «Анимации». Шрифт (пять вариантов) остаётся выпадающим списком.
3. Русские подписи выравнивания укорочены до «Слева», «По центру», «Справа», чтобы влезать в сегмент.
4. **Плоские строки.** `settingsCard` больше не рисует подложку `surface`: строки настроек и минимодалок лежат на фоне, отступ слева 12 + 16dp; скругление осталось только для волны нажатия. Заголовки секций — 13sp `textSecondary` вместо акцента. Заголовок минимодалки — 26sp Light.
5. Новых зависимостей и разрешений нет.

## Критерии приёмки
- **AC-69.1.** Given минимодалка «Анимация», When нажать `motion_space_NONE`, Then смена спейса без анимации, вариант отмечен как выбранный.
- **AC-69.2.** Given минимодалка «Текст», Then `font_weight_segments`, `text_size_segments`, `text_align_segments` видны без раскрытия списков.
