# ADR-0066. Редизайн, этап 2: режим редактирования — сетка точками, текстовые вкладки, кнопка «Готово»

Статус: принято по указанию владельца, 2026-11-28. Меняет AC-37.1, AC-37.2 и AC-37.4 в части кнопки «Готово».

## Контекст
Второй этап редизайна из ADR-0065: экран «Edit mode» на странице redesign холста. Иконки внизу (фон, текст, тема, анимация, «?», шестерёнка) читались как набор одинаковых кружков; владелец утвердил вариант с текстовыми вкладками и одной кнопкой «Готово».

## Решения
1. **Сетка виджетов — точки.** В каждой свободной клетке по центру точка радиусом 1,5dp цвета `textSecondary` с прозрачностью 35 % вместо скруглённых прямоугольников. Тег `widget_grid` прежний.
2. **Ручка строки — шесть точек** (`ic_drag`) 20dp цвета `textSecondary` без круглой подложки: строка сама её подложка. Зона захвата прежняя, 48dp.
3. **Строка добавления** — две текстовые кнопки слева: «+ Добавить приложение» и «+ Добавить папку», 16sp `textSecondary`, иконки 16dp без подложки. Теги `home_add_app`, `home_add_folder` прежние.
4. **Нижняя плашка в режиме редактирования:** слева текстовые вкладки «Фон», «Текст», «Тема», «Анимация» (14sp, `textSecondary`, высота 48dp, прокручиваются по горизонтали, если не влезают); справа кнопка-пилюля «Готово» 96 × 40dp цвета акцента с текстом цвета фона. Вне режима — карандаш на тональной подложке цвета `textPrimary`. Плашка лежит на полупрозрачной подложке фона, поэтому ADR-0021 соблюдён.
5. **Советов по редактированию больше нет:** кнопка «?», `Overlay.EditTips`, `EditTipsSheet` и строки `edit_tip*` удалены на всех языках; советы остаются в Настройки → Советы. AC-37.2 отменён.
6. Кнопка «Добавить виджет» над панелью остаётся пилюлей на подложке. Новых зависимостей и разрешений нет.

## Критерии приёмки
- **AC-66.1.** Given режим редактирования, Then видны вкладки `home_edit_background`, `home_edit_text`, `home_edit_theme`, `home_edit_motion`, кнопка `home_add_app`, нет `home_edit_tips` и `home_settings`; When нажать `home_edit` («Готово»), Then режим закрывается.
