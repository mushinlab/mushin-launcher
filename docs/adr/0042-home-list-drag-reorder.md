# ADR-0042. Перестановка строк главного экрана перетаскиванием

Статус: принято по указанию владельца, 2026-11-11. Дополняет AC-37.1. Удержание строки (п. 1 и 4) заменено ручкой перетаскивания в ADR-0043. Выпущено в 0.10.0.

## Контекст
Владелец: сделать перестановку элементов списка на главном экране перетаскиванием с нормальной анимацией. Раньше порядок менялся только в редакторе спейса.

## Решения
1. Перестановка работает в режиме редактирования: удержание строки (системный таймаут долгого нажатия) начинает перетаскивание. Касание строки по-прежнему открывает её минимодалку (AC-37.1). Вне режима удержание открывает popup, как раньше (трактовка агента: так жест не конфликтует с popup).
2. Поднятая строка идёт за пальцем, слегка увеличена (1,03) и подсвечена `accent` 12 %, рисуется поверх соседей. Когда она проходит половину соседней строки, соседняя плавно (≤ 200 мс, `Motion.TRANSITION_MS`) переезжает на освободившееся место. У краёв списка строка останавливается в крайней ячейке и не выходит за список. Удержание без движения с отпусканием ничего не открывает.
3. При отпускании строка анимированно встаёт в свою ячейку. Порядок сохраняется одной транзакцией: строка занимает место той, на чьё место её поставили, в полном списке спейса, так что элементы сверх видимой ёмкости не теряются. До прихода новых данных список показывает локальный порядок, без мигания.
4. Прокрутка списка, начатая до срабатывания удержания, отменяет перетаскивание; автопрокрутки у краёв нет.
5. Accessibility: в режиме редактирования у строки действия «Переместить раньше/позже».
6. Новых зависимостей нет.
