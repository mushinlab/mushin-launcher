# ADR-0039. Компактная верхняя панель виджетов

Статус: принято по указанию владельца, 2026-11-08; уточнено 2026-11-08 — часы перенесены в ячейку панели. Заменяет компоновку ADR-0038; сборка только для проверки в эмуляторе, без релиза.

## Контекст
После проверки 0.8.0 владелец отклонил избыточную высоту, две панели и подвижные часы. Запрос: только верхняя панель, маленькие виджеты, стандартная панель с одним или двумя виджетами в ряд/колонку, расширенная до четырёх (2×2), обычное перетаскивание.

## Решения
1. Одна панель над списком приложений. Стандартная — до двух виджетов, расположение «В ряд» / «В колонку»; расширенная — до четырёх, две колонки. Пустая панель вне редактирования не занимает места. Нет горизонтальной прокрутки и размеров S/M/L.
2. Часы — встроенная ячейка панели с зарезервированным id 0 (Android не выдаёт id 0). По умолчанию первая, входит в лимит, переносится и убирается как любой виджет. В редактировании на ячейке часов кнопка «Настроить» по центру поверх содержимого (минимодалка «Часы»: формат, размер, дата; переключатель «Показывать время» удалён) и «Убрать» в правом верхнем углу, на остальных — только «Убрать». Убранные часы — первый пункт выбора; выбор добавляет ячейку и открывает минимодалку. Размер часов в ячейке — 40/48/56 sp, дата в коротком формате. Вне редактирования касание часов открывает приложение «Часы».
3. Ячейка высотой 112 dp, ширина — половина экрана за вычетом полей 24 dp и промежутка 8 dp. Одиночный виджет не растягивается на весь экран. Часы и виджеты, которые меньше ячейки, центрируются в ней. Пустые строки не резервируются. В редактировании следующее свободное место — ячейка добавления того же размера; содержимое ячеек в редактировании приглушено, чтобы кнопки читались.
4. Собственная минимодалка выбора показывает название виджета и приложения и только провайдеры, минимальный допустимый размер которых с системными полями помещается в ячейку. Если ось разрешено изменять, учитывается minResize, иначе min. Никакого масштабирования большого виджета. Привязка и настройка остаются штатными Android-экранами; отмена освобождает id.
5. В редактировании удержание по системному таймауту начинает перенос. Отпускание над другой ячейкой меняет порядок с сохранением по спейсу. Вне редактирования касания получает виджет. Есть accessibility-действия перемещения. В стандартный режим нельзя перейти с более чем двумя экземплярами: минимодалка объясняет необходимость убрать лишние.
6. Локальный формат виджетов v3 читает v1 и v2: оба списка объединяются сверху в прежнем порядке, часы становятся первой ячейкой; если ячеек больше ёмкости сохранённого режима, выбирается расширенная панель. Если в настройках время было скрыто, часы убираются из всех панелей один раз, флаг сбрасывается. Существующие id не удаляются при миграции. Все ячейки в пределах ёмкости показываются, даже если провайдер не помещается (обрезка), чтобы не было невидимых занятых мест; сверх ёмкости — только в управлении с пояснением. Снимок главного экрана использует тот же кодек; Room и ключи настроек не меняются.
7. Новых зависимостей и разрешений нет. Номер версии не меняется; публикация и релиз запрещены текущим запросом.

## Проверки
Unit: геометрия переноса, лимиты и миграция v1, сохранение режима/ориентации/порядка. UI API 36: неподвижные часы, пустая панель, добавление/удаление, стандартная строка/колонка, расширенная сетка, перенос, перезапуск. Обязательный визуальный просмотр скриншотов эмулятора.
