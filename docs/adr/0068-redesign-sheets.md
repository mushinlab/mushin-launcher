# ADR-0068. Редизайн, этап 4: меню спейсов и действий приложения — шторка снизу

Статус: принято по указанию владельца, 2026-11-28. Меняет AC-06.1, AC-06.3 и AC-06.4.

## Контекст
Четвёртый этап редизайна из ADR-0065: экраны «Spaces · tap the space name» и «App actions · long press» на странице redesign холста. Popup у точки касания с рядом иконок и радиокнопками заменён шторкой снизу с текстовыми строками.

## Решения
1. **`BottomPanel`** в `core:ui`: затемнение `PopupStyle.scrim` и шторка у нижнего края во всю ширину, цвет `surface`, верхние углы 28dp, полоска-ручка, поля 28dp, прокрутка при нехватке высоты. Затемнение проявляется, а шторка выезжает за `Motion.TRANSITION_MS`. Касание затемнения закрывает шторку. Теги `popup` и `popup_scrim` прежние. Строки — `SheetItem` (не ниже 50dp), заголовок — `SheetTitle` (26sp, Light). Удержание строки вынесено из `PanelItem` в общий `Modifier.holdToFire`.
2. **Меню спейсов** (нажатие нижней плашки): спейсы строками 26sp Light; текущий — `textPrimary` с точкой акцента 8dp справа, остальные — `textSecondary`. Удержание строки по-прежнему открывает настройки спейса, свайп вверх по шторке — приватный спейс.
3. **Действия приложения** (удержание строки): заголовок — название приложения, ниже строками «Переименовать», «О приложении», «Убрать из спейса» (если приложение в спейсе), «Удалить» красным (не для системных). Списка спейсов в этой шторке больше нет: спейс выбирается нажатием плашки.
4. Точка якоря у `Overlay.Popup` больше не нужна и удалена. Папки, подсказка и меню в поиске остаются якорными popup.
5. Галочки «В спейсах» из макета (добавить приложение в несколько спейсов прямо из шторки) — новая функция, в этот этап не вошла. Новых зависимостей и разрешений нет.

## Критерии приёмки
- **AC-68.1.** Given удержание строки приложения, Then шторка снизу: `popup_rename`, `popup_about`, `popup_remove` идут сверху вниз, строк `popup_env_*` нет; касание затемнения закрывает шторку.
- **AC-68.2.** Given нажатие плашки, Then шторка со строками `popup_env_*`, текущий спейс отмечен как выбранный; нажатие другого спейса переключает и закрывает шторку.
