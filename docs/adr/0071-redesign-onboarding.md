# ADR-0071. Редизайн, этап 7: онбординг из четырёх слайдов с полоской прогресса

Статус: принято по указанию владельца, 2026-11-28.

## Контекст
Седьмой этап редизайна из ADR-0065: экраны «First run» на странице redesign холста. Шесть слайдов при первом запуске — много; советы о раскладке списка и о «памяти» нужны позже и остаются в Настройки → Советы.

## Решения
1. Онбординг показывает советы `SPACE`, `SEARCH`, `STYLE` и последний слайд «Ещё советы» — четыре слайда (`OnboardingPager.TIPS`, `SLIDES = 4`). Раздел «Советы» по-прежнему показывает все пять.
2. Вместо точек внизу — полоска прогресса под статус-баром: отрезки по числу слайдов, пройденные и текущий — цветом акцента, остальные — `divider`. Тег `onboarding_dots` и описание позиции для доступности прежние.
3. Заголовок слайда — 32sp Light, текст — 16sp `textSecondary`, оба выровнены влево с полями 28dp. Анимации советов прежние.
4. Интро приватного спейса не менялось. Новых зависимостей и разрешений нет.

## Критерии приёмки
- **AC-71.1.** Given первый запуск, Then четыре слайда `onboarding_slide_0..3`, после последнего «Готово» онбординг больше не показывается.
