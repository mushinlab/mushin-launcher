# ADR-0062. Цвет часов меняется вместе с фоном, настройки из поиска проявляются поверх поиска

Статус: принято по указанию владельца, 2026-11-28. Дополняет ADR-0060.

## Контекст
1. При смене спейса часы заметно мигают, будто подбирают контраст. Цвет часов пересчитывался сразу: сначала по старой картинке с яркостью нового спейса, затем по новой картинке — мгновенно, хотя сама картинка проявляется секунду (ADR-0060).
2. Если открыть настройки шестерёнкой в поиске, экран неприятно мигает: поиск гаснет, а настройки проявляются одновременно, и в середине сквозь оба просвечивает главный экран.

## Решения
1. Пока картинка фона ещё не принадлежит текущему спейсу, часы не пересчитывают цвет.
2. Когда фон проявляется (ADR-0060), цвет часов переходит к новому за ту же секунду. Без смены картинки (первый показ, пересоздание экрана, страница соседа при листании) цвет ставится сразу, как раньше; изменения в пределах одной картинки — за 200 мс.
3. При переходе из поиска в настройки поиск остаётся непрозрачным, пока настройки обычным fade-in (200 мс) проявляются поверх него, и убирается в конце перехода. Главный экран при этом не виден.
4. Новых зависимостей и разрешений нет.

## Критерии приёмки
- **AC-62.1.** Given часы светлые на тёмной теме, When появляется красный фон, Then в первые кадры часы остаются светлыми, а к концу проявления — тёмными.
- **AC-62.2.** Given открыт поиск над красным фоном, When нажать шестерёнку, Then ни в одном кадре перехода красный фон главного экрана не виден, и открываются настройки.
