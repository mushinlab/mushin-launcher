# ADR-0050. Свайп по нижней плашке листает спейсы

Статус: принято по указанию владельца, 2026-11-21. Меняет AC-05.2 (у переключения спейса появляется анимация) и дополняет AC-06.1 (нижняя плашка) из ADR-0049.

## Контекст
Владелец: горизонтальный свайп по нижней плашке главного экрана переключает спейс с анимацией слайда, страница за страницей, и новый фон приезжает вместе со страницей. Сейчас тап по плашке открывает popup (ADR-0049), свайп вверх — поиск (0.10.2), горизонтальные свайпы по умолчанию ни к чему не привязаны. AC-05.2 требует переключение спейса без анимаций.

## Рассмотренные варианты
1. **Слайд содержимого без обоев.** Обои — общий слой, новый фон мягко проявляется. Проще по памяти и коду, но владелец хочет, чтобы фон приезжал вместе со страницей.
2. **Слайд страницы вместе с обоями.** Две страницы компонуются одновременно, каждая со своей палитрой, обоями и содержимым. Выбран.
3. **Страницы едут за пальцем.** Отклонён: дороже в реализации, а ожидаемый эффект даёт и слайд после отпускания.

## Решения
1. Жест — горизонтальный свайп, начатый на нижней плашке вне её кнопок, когда главный экран не в режиме редактирования. Пороги те же, что у остальных свайпов: 96dp пути или бросок от 48dp при 1000dp/с, направление по доминирующей оси. Кнопки плашки (настройки, редактирование, подсказка, инструменты) остаются заблокированными для жеста, как сейчас.
2. Порядок — как в popup (`sort_order, id`). Свайп влево — следующий спейс, вправо — предыдущий, по кругу. Если спейс один, жест ничего не делает.
3. Анимация — две страницы одновременно, 200 мс (`Motion.TRANSITION_MS`). При свайпе влево уходящая страница едет влево, приходящая въезжает справа; при свайпе вправо — наоборот.
4. Страница — это цвет фона палитры, обои, строки, часы, виджеты и нижняя плашка с именем спейса. Обои — часть страницы и приезжают вместе с ней. Плавающая кнопка редактирования и слой следа рисунка не двигаются.
5. Слайд начинается, когда состояние приходящего спейса и его фон готовы; до этого на экране стоит текущая страница. Фон декодируется локально из файла. Если фона нет или декодирование не удалось, страница стартует с цветом палитры. Старый и новый полноразмерные фоны живут в памяти только на время анимации.
6. Пока идёт слайд, ввод игнорируется; следующее касание работает уже с новой страницей.
7. Переключение спейса из popup проигрывает тот же слайд. Переключение из настроек анимации не имеет: главного экрана в этот момент не видно.
8. Тап по плашке по-прежнему открывает popup, свайп вверх — поиск. Popup остаётся доступным путём для TalkBack; новых действий доступности не добавляем.
9. Горизонтальный свайп, начатый на плашке, больше не запускает действия, привязанные к `LEFT`/`RIGHT`. В остальной части экрана привязки не меняются; по умолчанию `LEFT`/`RIGHT` — `None`.

## Вопросы, решённые без владельца
| № | Вопрос | Решение |
|---|---|---|
| Q-184 | Листать по кругу или упираться в края? | По кругу: два спейса при старте, жест туда и обратно всегда работает одинаково |
| Q-185 | Что важнее на плашке — привязка `LEFT`/`RIGHT` или листание? | Листание: жест начат на плашке, это её действие; привязки работают в остальной части экрана |
| Q-186 | Начинать слайд сразу или ждать декод фона? | Ждать: иначе обои прыгнут в середине анимации. Декод локальный, без таймаутов |
| Q-187 | Должна ли кнопка редактирования ехать со страницей? | Нет: это общий элемент, он не принадлежит спейсу |

## Проверка
- **AC-50.1.** Given главный экран вне редактирования и больше одного спейса, When горизонтальный свайп влево по плашке, Then текущим становится следующий спейс по порядку popup и обе страницы едут влево 200 мс; свайп вправо — предыдущий.
- **AC-50.2.** Given один спейс, When свайп по плашке, Then ничего не меняется и анимации нет.
- **AC-50.3.** Given режим редактирования, When горизонтальный свайп по плашке, Then спейс не меняется; тап по плашке popup не открывает, свайп вверх поиск не запускает — плашка в этот момент показывает инструменты, жесты по ней молчат.
- **AC-50.4.** Given выбор спейса в popup, Then проигрывается тот же слайд. Given переключение из настроек, Then анимации нет.
- **AC-50.5.** Приходящая страница показывает свою палитру, обои, строки, часы, виджеты и имя спейса; обои движутся вместе со страницей; кнопка редактирования остаётся на месте.
- **AC-50.6.** Во время слайда касания игнорируются.
- **AC-50.7.** Свайп по плашке не запускает привязки `LEFT`/`RIGHT`; свайпы с остальной части экрана работают как раньше.

Проверки после реализации: unit на выбор соседнего спейса (вперёд, назад, по кругу, один спейс); UI на API 36 — свайп по плашке меняет спейс и проигрывает слайд, тап и свайп вверх не сломаны, в режиме редактирования жест молчит; ручная проверка анимации и обоев на эмуляторе.
