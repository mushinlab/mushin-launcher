# ADR-0033. «Ввод жестами» в «Жестах», страница «Конфиденциальность», без «Дополнительно»

Статус: принято (указание владельца; трактовки агента помечены). 2026-10-24. Изменяет ADR-0017 и ADR-0024 (раздел «Память»), ADR-0029 п. 4.

## Контекст
Владелец:
- Освободить «Систему» от «Памяти» и выученных жестов. Перенести их отдельным разделом на страницу «Жесты», над «Линией».
- По умолчанию выключить эти настройки и ввод жестами вне клавиатуры. По умолчанию работает только простой ввод свайпом по клавиатуре, без обучения.
- Сделать одну строку «Ввод жестами» с переключателем. Выключен — настройки и функции скрыты, ничего не запоминается.
- Под переключателем — выученные жесты и настройка подсказок с описанием. Подсказка на главном экране получает крестик, который открывает две кнопки: «Скрыть» и «Больше не предлагать».
- «Анимацию нажатия» убрать в стили. «Дополнительно» убрать. Добавить страницу «Конфиденциальность»: список данных свёрнут по умолчанию, сверху красная «Стереть память» с системным подтверждением.

## Решения
1. **Настройки.**
   - `LauncherSettings.gestureInput`: по умолчанию `false`, ключ DataStore `gesture_input`. Выключено и у тех, кто обновляется (трактовка агента: «по умолчанию выключен»).
   - `LauncherSettings.learnHints`: по умолчанию `true`, ключ `learn_hints`.
2. **Пока «Ввод жестами» выключен:**
   - рисунок на главном экране не распознаётся и не рисуется; свайпы работают;
   - при запуске приложения из поиска жесты не запоминаются;
   - выученные жесты не участвуют в подсказках клавиатуры;
   - подсказка «Что вы имели в виду?» не появляется.
   Ввод свайпом по клавиатуре работает как раньше. Уже выученные жесты не удаляются, просто не используются.
3. **«Настройки → Жесты»**, сверху вниз:
   - свайпы;
   - раздел «Ввод жестами»: переключатель и пояснение;
   - при включённом вводе: «Подсказки обучения» (переключатель и пояснение) и раздел «Выученные жесты» — «Добавить жест», приложения с рисунками, «Забыть все жесты»;
   - «Линия».
4. **Подсказка на главном экране.**
   - Справа в карточке кнопка ✕. Она раскрывает в карточке две кнопки: «Скрыть» и «Больше не предлагать».
   - «Больше не предлагать» выключает «Подсказки обучения».
   - Пока кнопки открыты, карточка не исчезает сама.
   - При выключенных подсказках промахи всё равно отвергаются вибрацией, а счётчик промахов сбрасывается.
   - «Перейти к обучению» открывает «Жесты → Добавить жест».
5. **«Анимация нажатия»** — в шторке «Тема» режима редактирования, после «Счётчика уведомлений» (трактовка агента: раздела «Стиль» нет с ADR-0029).
6. **«Дополнительно» удалено.**
   - Маршруты `Advanced`, `Press` и `Memory` убраны.
   - `MemoryApp` и `MemoryPickApp` остались и открываются из «Жестов».
7. **«Настройки → Система → Конфиденциальность»** (`SettingsRoute.Privacy`):
   - красная строка «Стереть память»; системный диалог подтверждения стирает историю запусков (счётчики, недавние, дни) и все выученные жесты (трактовка агента: «память» — всё выученное);
   - пояснение и текст о конфиденциальности (раньше был внизу «Системы»);
   - свёрнутая строка «Сохранённые данные» с ▾; раскрывает историю запусков и полезность приложений в текущем спейсе.
   - Отдельной кнопки «Стереть историю запусков» больше нет: это делает «Стереть память».
8. **Системный диалог** вынесен в общий `SystemConfirmDialog`; удаление спейса пользуется им же.
9. Совет «Научите лаунчер», README, тексты для магазина и политика конфиденциальности ведут в «Жесты» и «Конфиденциальность».
