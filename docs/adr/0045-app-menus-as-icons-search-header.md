# ADR-0045. Меню приложения иконками на главном и в поиске, «скрытые» в шапке поиска

Статус: принято по указанию владельца, 2026-11-16. Изменяет AC-06.3, добавляет AC-45.1–45.3. Заменяет в ADR-0041 решение «„Убрать из спейса“ в popup нет»; «Скрыть» в popup главного экрана по-прежнему нет. Выпущено в 0.10.0.

## Контекст
Владелец по трём скриншотам со своего телефона:
- popup приложения на главном экране: нет иконки «Убрать из спейса»; иконку удаления перенести влево и сделать красной;
- меню результата в поиске: пункт «Убрать из спейса / Добавить в спейс» не нужен, остальные заменить иконками, как в popup главного экрана;
- меню настроек поиска: почти все пункты, кроме «Показать скрытые», не нужны; «скрытые» вынести иконкой слева от шестерёнки, шестерёнка просто ведёт в настройки; убранные опции оставить включёнными.

## Решения
1. Popup приложения на главном экране — ряд иконок слева направо: «Удалить» (корзина, красная), «О приложении», «Переименовать», «Убрать из спейса» (крестик, как в строке режима редактирования). «Удалить» по-прежнему скрыта для системных приложений, «Убрать из спейса» показана, когда приложение есть в текущем спейсе. Нажатие убирает строку сразу, без подтверждения и уведомления.
2. Меню результата в поиске — заголовок с названием и такой же ряд иконок: «Удалить» (красная), «О приложении», «Переименовать», «Скрыть» (зачёркнутый глаз) или «Показать» (глаз) для скрытого. Пункта про спейс нет; добавление из поиска и уведомления «Добавлено в…», «Убрано из…», «…заполнен» удалены.
3. Красный — `MushinColors.danger`, фиксированный `#E5534B` во всех темах (тот же, что на экране приватности). Красится знак; контур кнопки остаётся цвета подписи.
4. В шапке поиска две кнопки: «Показать скрытые» слева и «Настройки» справа. Скрытые не показаны — зачёркнутый глаз цвета подписи; показаны — глаз акцентным цветом. Состояние, как раньше, действует до закрытия поиска. Шестерёнка закрывает поиск и открывает настройки. Меню настроек поиска удалено.
5. Опции «Исправлять опечатки», «Исправлять раскладку», «Транслитерация» и «Цветные иконки» удалены вместе с настройками `searchFuzzy`, `searchLayoutSwap`, `searchTranslit`, `searchColoredIcons`: поиск всегда работает со всеми тремя исправлениями и показывает цветные иконки. Сохранённые значения больше не читаются. `SearchOptions` в `:core:search` остаётся для тестов движка.
6. Новые знаки `Glyph.HIDE` и `Glyph.SHOW` (глаз) в `:core:ui`.

## Вопросы, решённые без владельца
| № | Вопрос | Решение |
|---|---|---|
| Q-166 | Куда именно «влево» ставить удаление? | Первой в ряду, перед «О приложении»; так же в меню поиска |
| Q-167 | Красить ли контур кнопки удаления? | Нет, только знак: контур у всех кнопок ряда одинаковый |
| Q-168 | Оставить ли убранные опции настройками без интерфейса? | Нет: настройка, которую нельзя изменить, оставила бы выключенное у тех, кто выключал. Опции всегда включены |
| Q-169 | «Цветные иконки» в поиске по умолчанию были выключены — включать? | Да, владелец сказал оставить всё включённым; поиск всегда цветной, независимо от настройки спейса |
| Q-170 | Как добавить приложение в спейс без пункта в поиске? | «Добавить приложение» на главном экране в режиме редактирования или на пустом списке |
| Q-171 | Нужно ли подтверждение для «Убрать из спейса» в popup? | Нет, как у крестика в режиме редактирования; приложение возвращается через «Добавить приложение» |
| Q-172 | Запоминать ли «Показать скрытые» между открытиями поиска? | Нет, как и раньше сбрасывается при закрытии |

## Что устарело
`docs/spec/ux.md`, строка «Settings → Поиск: fuzzy, раскладка, транслит (вкл/выкл)» — этих переключателей нет.

## Проверки
Unit: меню поиска без признака спейса, панели поиска без меню настроек, настройки без четырёх полей. UI API 36: порядок иконок popup и удаление строки через «Убрать из спейса»; ряд иконок в меню поиска без пункта про спейс; скрытие приложения и переключатель в шапке; шестерёнка открывает настройки. Вручную на эмуляторе: три меню, красная корзина, оба состояния глаза.
