# ADR-0027. Фон спейса — в «Стиле»

Статус: принято (указание владельца; трактовки агента помечены). 2026-10-18. Изменяет ADR-0020, п. 2–3.

## Контекст
Владелец: «background image перемести в style, покажи хинт маленький, что настройка для текущего спейса».

## Решения
1. Раздел «Фон» (миниатюра, «Изменить фон», «Убрать фон», пояснение) перенесён из настроек спейса в «Стиль». Он стоит сразу после палитры и цветных значков текущего спейса, перед «Текстом».
2. Из настроек спейса раздел убран (трактовка агента: «перемести» — не дублировать). Фон по-прежнему хранится у каждого спейса отдельно, раздел в «Стиле» работает с текущим спейсом.
3. Под заголовком «Фон» — короткая подсказка: «Только для текущего спейса «<имя>». У каждого спейса свой фон.» (7 языков).
4. Редактор фона, его кнопки и хранение не меняются. «Сохранить» и «Отмена» возвращают в «Стиль».

| # | Вопрос | Решение агента |
|---|---|---|
