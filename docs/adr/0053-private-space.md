# ADR-0053. Приватный спейс

Статус: принято по указанию владельца, 2026-11-21. Дополняет ADR-0007 (спейсы) и ADR-0050 (листание спейсов).

## Контекст
Владелец попросил приватный спейс: приложения, добавленные в него, автоматически скрываются из меню основного спейса; вход только по PIN; сброс — через Advanced → Reset app; если не вернуться в Default вручную, через 2 минуты происходит автоматический возврат. Отдельно при первом запуске, вне мини-подсказок, показывается обучение открытию приватного спейса с обязательной галочкой «Я знаю, как пользоваться приватным спейсом».

## Решения
1. Приватный спейс — единственный спейс типа `PRIVATE`. Он создаётся при первом запуске с локализованным именем («Приватный»), фиксированной палитрой `Night` и без обоев. В popup и в обычном списке спейсов настроек его нет; менять его палитру, обои и имя нельзя.
2. Вход: тап по нижней плашке открывает popup, свайп вверх по открытому окошку открывает ввод PIN. Если PIN ещё не задан, он создаётся: 4 цифры вводятся дважды. Хранятся только соль и хеш PBKDF2-HMAC-SHA256 (120 000 итераций, 256 бит, случайная соль 16 байт); сам PIN не хранится. Забытый PIN сбрасывается только через Advanced → Reset app.
3. Приложения приватного спейса скрыты из избранного, папок, поиска и рекомендаций всех остальных спейсов; внутри приватного они видны и находятся поиском. Скрытие — динамическая фильтрация: если приложение убрать из приватного, оно снова появляется в остальных спейсах.
4. Свайп по нижней плашке (ADR-0050) пропускает приватный спейс; начатый внутри приватного, он ничего не делает. В popup приватного спейса нет.
5. Авто-выход: через 2 минуты после последнего касания в приватном спейсе лаунчер сам переключается на NORMAL и закрывает оверлеи. Любое касание в приватном спейсе продлевает сессию. Ручное переключение на другой спейс отменяет таймер и происходит без слайда, чтобы приватная страница не мелькала.
6. Обучение показывается один раз при первом запуске после онбординга, отдельно от мини-подсказок: карточка объясняет тап по нижней плашке и свайп вверх по окошку. Кнопка «Продолжить» неактивна, пока не отмечена галочка «Я знаю, как пользоваться приватным спейсом». Флаг — `private_hint_seen`.
7. Advanced → Reset app в разделе System настроек просит подтверждение и удаляет все спейсы, их списки, папки, переопределения, историю, обучение жестам, настройки и PIN приватного спейса; затем заново создаются Default и Work, показывается онбординг, а приватный спейс создаётся пустым при следующем запуске.
8. Новых зависимостей и разрешений нет; данные не покидают устройство, сеть не используется.

## Вопросы, решённые с владельцем
| № | Вопрос | Решение |
|---|---|---|
| Q-192 | Как задаётся PIN? | 4 цифры при первом открытии, подтверждение повтором |
| Q-193 | Где скрывать приложения? | Везде, кроме приватного спейса, включая поиск |
| Q-194 | Когда срабатывает авто-выход? | Через 2 минуты после последнего касания |
| Q-195 | Где настраивать приватный спейс? | Нигде: палитра и обои фиксированы |

## Проверки
- **AC-53.1.** Given приватный спейс без PIN, When свайп вверх по popup, Then показывается ввод PIN; после двух одинаковых наборов из 4 цифр открывается приватный спейс, хеш сохранён. Given PIN задан, Then тот же жест просит PIN, верный открывает спейс, неверный показывает ошибку и не меняет спейс.
- **AC-53.2.** Given приложение в приватном спейсе, Then его нет в избранном, папках, поиске и рекомендациях других спейсов; внутри приватного оно есть и находится поиском.
- **AC-53.3.** Given приватный спейс открыт, When 2 минуты без касаний, Then лаунчер сам переключается на Default; касание продлевает сессию.
- **AC-53.4.** Given первый запуск после онбординга, Then показано обучение, не входящее в мини-подсказки; без галочки «Я знаю, как пользоваться приватным спейсом» его нельзя закрыть, после закрытия оно больше не появляется.
- **AC-53.5.** Given Advanced → Reset app и подтверждение, Then удаляются все спейсы, списки, настройки и PIN, создаются Default и Work, онбординг показывается заново.
- **AC-53.6.** Приватного спейса нет в popup и в списке спейсов настроек; свайп по нижней плашке его пропускает, внутри него свайп спейс не меняет.

Unit: выбор соседнего спейса в обход приватного, создание единственного приватного спейса, сброс данных с повторным посевом, сохранение и проверка PIN. UI API 36: создание PIN по свайпу, вход по PIN, скрытие приложения из списка и поиска, обучение с галочкой, отсутствие приватного в popup. Авто-выход через 2 минуты и Reset app проверяются вручную и на эмуляторе.
