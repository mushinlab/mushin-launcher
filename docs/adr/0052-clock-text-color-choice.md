# ADR-0052. Выбор цвета шрифта часов

Статус: принято по указанию владельца, 2026-11-21. Дополняет решение 5 ADR-0049 (автоматический контраст часов).

## Контекст
ADR-0049 сделал цвет цифр и даты автоматическим: белый или чёрный по яркости участка фона под текстом. Владелец попросил в настройках часов выбирать светлый или тёмный цвет шрифта вручную.

## Решения
1. Новая настройка `clock_ink`: `AUTO` (по умолчанию), `LIGHT` (белый текст), `DARK` (чёрный текст).
2. В минимодалке «Часы» под выбором формата появляется пункт «Цвет шрифта» с тремя значениями: «Авто», «Светлый», «Тёмный».
3. `LIGHT` и `DARK` действуют на время и дату одновременно и не зависят от фона; переход цвета — `Motion.TRANSITION_MS`.
4. `AUTO` сохраняет алгоритм ADR-0049 без изменений: выбор из белого и чёрного по контрасту с фоном под текстом.
5. Значение хранится в DataStore под ключом `clock_ink` и в снапшоте главного экрана версии 8; старые снапшоты читаются как `AUTO`.
6. Новых зависимостей и разрешений нет.

## Проверки
- **AC-52.1.** Given минимодалка «Часы», Then есть пункт «Цвет шрифта» с «Авто» / «Светлый» / «Тёмный»; по умолчанию «Авто»; выбор сохраняется и переживает перезапуск.
- **AC-52.2.** Given «Светлый», Then время и дата белые независимо от фона; given «Тёмный», Then чёрные; переход ≤ `Motion.TRANSITION_MS`.
- **AC-52.3.** Given «Авто», Then действует автоматический контраст ADR-0049.

Unit: сохранение настройки, снапшот v8 и чтение старых версий. UI API 36: выбор в минимодалке меняет цвет часов, перезапуск сохраняет выбор. Визуальная проверка на светлом и тёмном фоне.
