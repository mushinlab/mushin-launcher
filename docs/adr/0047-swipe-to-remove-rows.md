# ADR-0047. Удаление строки свайпом в режиме редактирования

Статус: принято по указанию владельца, 2026-11-16. Изменяет AC-37.1, добавляет AC-37.11. Заменяет кнопки «заменить» и «убрать» в строке из ADR-0043 (п. про строки редактирования).

## Контекст
Владелец: убрать кнопку «заменить», удаление сделать свайпом. Чем дальше тянешь влево, тем тяжелее; на пороге — тактильный отклик; при этом постепенно появляется кнопка удаления на красноватом полупрозрачном фоне. Убрать приложение можно только после «оттянул, отпустил, нажал». При входе в режим редактирования приложение показывает, что строку можно смахнуть.

## Решения
1. В строке режима редактирования остаются ручка слева и название. У папки справа остаётся карандаш — он открывает редактор папки, другого входа в него для непустой папки нет. У приложений кнопок нет; замена приложения и маршрут `ReplaceApp` удалены.
2. Свайп влево сдвигает строку с нарастающим сопротивлением: смещение = предел × (1 − e^(−путь/предел)), предел 120dp. Справа открывается полоса цвета `danger` с прозрачностью 28 %, в ней корзина, проявляющаяся пропорционально смещению.
3. Порог — 72dp смещения. При его пересечении — один тактильный отклик. Отпустили за порогом — строка остаётся открытой на 72dp, корзина нажимается; не дотянули — строка закрывается. Переходы 200 мс.
4. Открытая строка закрывается нажатием на неё, свайпом обратно дальше половины, началом свайпа другой строки, перетаскиванием за ручку и выходом из режима редактирования. Открыта не больше одной строки.
5. При входе в режим редактирования все строки один раз сдвигаются на 28dp и возвращаются (два перехода по 200 мс).
6. Для TalkBack у строки есть действие «Убрать …» рядом с «Переместить раньше/позже».
7. Подсказка «Расставьте список» и текст подсказки режима редактирования переписаны под свайп на семи языках.

## Вопросы, решённые без владельца
| № | Вопрос | Решение |
|---|---|---|
| Q-174 | Что делать с карандашом у папки? | Оставить: это редактор папки, а не замена |
| Q-175 | Подсказка свайпа — у одной строки или у всех? | У всех сразу, при каждом входе в режим редактирования |
| Q-176 | Удалять ли замену приложения совсем? | Да, вместе с маршрутом и строками: войти в неё больше неоткуда |

## Проверки
Unit: сопротивление, порог, открытое состояние, закрытие. UI API 36: свайп открывает корзину и нажатие убирает строку; короткий свайп закрывается; вторая строка закрывает первую; папка — карандаш и удаление свайпом. Полный набор 116/116. Вручную на эмуляторе: подсказка и открытая строка. Анимация подсказки Tips глазами не просмотрена.
