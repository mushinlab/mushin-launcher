# ADR-0014. Публикация: идентификатор, контакт, лицензия, ключ подписи

Статус: принято (указания владельца). 2026-10-15.

## Решения
1. **`applicationId` — `com.mushinlab.launcher`** (ответ на Q-79). Сменён до первой публикации в Google Play, потому что потом его изменить нельзя.
   - `namespace`, пакеты в коде, схема БД и тест-теги остаются `com.bluecubelabs.env`, как в ADR-0007.
   - Бенчмарки запускают активность явно: пакет `com.mushinlab.launcher`, класс `com.bluecubelabs.env.MainActivity`.
   - Сборка 0.1.0 на GitHub вышла со старым идентификатором. Для Android это другое приложение: 0.1.1 ставится рядом, а не поверх, и данные не переносятся.
2. **Публичный контакт — `mushin-lab@proton.me`** (ответ на Q-71). Указан в политике конфиденциальности и в разделе «Конфиденциальность» в приложении. Разработчик в политике — Mushin Lab, как в сертификате подписи и в README.
3. **Лицензия — Apache-2.0** (ответ на Q14 из `docs/spec/business.md`). Репозиторий публичный: github.com/mushinlab/mushin-launcher.
4. **Ключ подписи** (ответ на Q-25). Владелец создал ключ сам, он хранится вне репозитория и подключается через `keystore.properties`. SHA-256 сертификата: `50:54:7D:78:43:AA:0A:87:FA:E3:4C:E2:0A:28:3A:A5:B1:4F:47:05:05:CB:98:1B:2A:A2:87:16:21:0F:87:29`. Им подписываются все релизы. Для Google Play его же стоит загрузить как ключ подписи приложения («Use existing app signing key»), чтобы сборки из GitHub и из Play обновлялись друг поверх друга.
