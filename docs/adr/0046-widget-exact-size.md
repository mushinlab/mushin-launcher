# ADR-0046. Виджет получает точный размер своей области

Статус: принято по указанию владельца, 2026-11-16. Изменяет AC-39.1. Заменяет «Виджеты меньше прямоугольника центрируются» в ADR-0040 (п. 8) и ADR-0039 (п. 3) для виджетов Android; встроенные часы по-прежнему по центру ячейки.

## Контекст
После 0.10.0 владелец добавил виджет Xiaomi Smart Plug: он нарисован маленьким посреди своей области, значок наложен на название. Причина: `WidgetFrame` измерял виджет с ограничением «не больше области» (`AT_MOST`). Корень макета с `match_parent` при таком измерении сжимается до содержимого, и элементы, привязанные к краям, накладываются друг на друга. На эмуляторе API 36 то же видно на «At a Glance»: 790 px вместо 911 px ширины.

## Решения
1. `WidgetFrame` измеряет виджет ровно по размеру прямоугольника (`EXACTLY`), как штатные лаунчеры. Тот же размер, как и раньше, сообщается провайдеру через `updateAppWidgetSize`.
2. Положение содержимого внутри области определяет сам виджет. Макет с собственным размером меньше области Android по-прежнему ставит по центру (`AppWidgetHostView`).
3. Отдельная раскладка `WidgetFrame` по центру удалена: виджет занимает всю область.

## Вопросы, решённые без владельца
| № | Вопрос | Решение |
|---|---|---|
| Q-173 | Оставить ли центрирование для виджетов, которые умеют растягиваться? | Нет: растягивающийся виджет должен заполнять область, иначе он не знает своего размера |

## Проверки
UI API 36: виджет с содержимым 10×10 в области 400×200 измеряется как 400×200 (до правки — 10×10); остальные тесты виджетов. Вручную на эмуляторе: «At a Glance» занимает всю ширину области. На устройстве Xiaomi не проверялось.
