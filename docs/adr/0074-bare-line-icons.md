# ADR-0074. Иконки — тонкие линии без подложки; режим редактирования — иконками

Статус: принято по указанию владельца, 2026-11-28. Меняет ADR-0021, AC-37.4 и решение 4 ADR-0066.

## Контекст
Владельцу не нравились иконки на круглой подложке и особенно обводка у кнопки удаления. Текстовые вкладки внизу режима редактирования (ADR-0066) не помещаются на других языках. Владелец утвердил доску «Icons — redesign» на холсте Claude Design.

## Решения
1. **Набор иконок перерисован** в одном стиле: сетка 24, линия 1,6 (галочка 2, точки ручки 2,8), скруглённые концы и углы, без заливки. Шестерёнка заменена ползунками, тема — круг со штриховкой половины. Добавлена иконка «Добавить папку» (`Glyph.FOLDER_ADD`).
2. **`GlyphButton` без подложки и обводки.** Область нажатия 48dp прежняя; при нажатии — мягкий круг `textPrimary` 8 % и волна. Цвет говорит сам: `textPrimary` — действие, акцент — «Готово», красный — удаление. `GlyphStyle` удалён.
3. **Над картинкой фона** (`LocalGlyphHalo`, включается на главном экране с фоном) за иконкой рисуется размытая тень цвета, контрастного её цвету (чёрная для светлой иконки, белая для тёмной). Это заменяет непрозрачную подложку ADR-0021.
4. **Режим редактирования:** внизу четыре иконки (фон, текст, тема, анимация) и галочка «Готово» цветом акцента; строка добавления — иконки «+» и «папка с плюсом»; «Добавить виджет» — иконка виджетов. Подписи остались описаниями для доступности, теги прежние.
5. Удаление виджета и спейса — красная корзина без обводки; иконка папки в строке и стрелка «Назад» в настройках — без подложки. Клавиши клавиатуры сохраняют свои подложки: это клавиши, а не иконки.
6. Новых зависимостей и разрешений нет.

## Критерии приёмки
- **AC-74.1.** Given любая фиксированная тема, Then `textPrimary`, `textSecondary`, акцент и красный дают контраст не ниже 3:1 с фоном спейса.
- **AC-74.2.** Given режим редактирования, Then внизу `home_edit_background`, `home_edit_text`, `home_edit_theme`, `home_edit_motion` и `home_edit` без текста на экране, с описаниями для доступности.
