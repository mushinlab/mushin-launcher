# ADR-0041. Действия приложения иконками, зазор над нижней панелью, высота строки от шрифта

Статус: принято по указанию владельца, 2026-11-11. Изменяет AC-03.2 и AC-06.3.

## Контекст
Владелец:
- В popup строки приложения сделать кнопки иконками в ряд: «О приложении», редактирование, удаление. «Скрыть» и «Убрать из спейса» убрать.
- Минимальный зазор от нижней границы списка до иконок нижней панели мал — сделать в 3 раза больше.
- Высота строки приложения на главном экране должна зависеть от размера шрифта: меньше текст — меньше кнопка.

## Решения
1. Popup строки приложения: заголовок с меткой, под ним один ряд `GlyphButton` (непрозрачная подложка, ADR-0021): «О приложении» (новый значок i), «Переименовать» (карандаш), «Удалить» (корзина, только для несистемных приложений). Подписи остаются описаниями для accessibility. Ниже, как раньше, — спейсы.
2. «Скрыть» и «Убрать из спейса» из этого popup удалены. Скрыть приложение можно из поиска, убрать из спейса — в режиме редактирования (AC-37.1).
3. Видимый зазор между концом списка и подложками кнопок нижней панели вырос с 8 до 24dp: над панелью добавлен отступ 16dp.
4. Высота строки главного экрана = 2,1 × высота строки текста, не меньше 48dp (минимальная зона касания). При размере M (26sp) это около прежних 64dp; S даёт ниже строку, L — выше. Прежний пол 64dp убран.
