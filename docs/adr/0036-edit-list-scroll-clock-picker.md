# ADR-0036. Прокрутка списка в режиме редактирования, центровка с иконкой, размер и скрытие часов, выбор приложений с нашей клавиатурой

Статус: принято (указание владельца; трактовки агента помечены). 2026-11-01. Заменяет ADR-0031 и п. «центр текста по центру экрана» ADR-0030; дополняет ADR-0035.

## Контекст
Владелец:
1. «Когда переходишь в режим edit, список приложений обрезается… давай явно покажем, что список превращается в scrollable блок, чтобы пользователь имел возможность редактировать все».
2. «Давай центровать текст по центру с учётом иконки. Сейчас иконка как position absolute».
3. «В панель редактирования времени добавим text size с 3 опциями. А также тоггл, чтобы убрать время вообще… В режиме edit, если время совсем скрыто, добавлять сверху невысокую панель с кнопкой "add time +"».
4. «Панель, которая открывается при клике на add apps, переделаем по принципу панели поиска… Клавиатура наша, приложения идут снизу наверх… инпут над клавиатурой».

## Решения
1. В режиме редактирования список — прокручиваемый блок высотой не больше пяти с половиной строк. Половина шестой строки и полоса прокрутки у правого края показывают, что список листается. Если строк пять или меньше, блок по высоте равен списку и не прокручивается. Высота меняется за 200 мс (ADR-0003). Пока тянут линию над списком, виден весь список, как раньше. При выходе из режима прокрутка сбрасывается в начало.
2. Строка «Добавить папку / Добавить приложение» стоит сразу под блоком и не прокручивается вместе со списком (трактовка агента: кнопки добавления всегда под рукой).
3. При выравнивании по центру по центру строки стоит пара «название + отступ + иконка» целиком; без иконки — само название. Выравнивание по краям не меняется.
4. В минимодалке «Часы» сверху переключатель «Показывать время», под ним, пока время показано, «Размер часов» (маленький 56 sp, средний 72 sp — прежний, крупный 96 sp), формат и дата.
5. Выключенное время убирает с главного экрана весь блок часов вместе с датой (трактовка агента: дата без времени выглядит как обломок). В режиме редактирования на месте часов — невысокая (48 dp) панель «Добавить время +»; нажатие снова включает время. Видимость и размер часов попадают в снимок главного экрана (версия 5), чтобы первый кадр после запуска не мигал.
6. «Добавить приложение», выбор приложений для папки и замена приложения по «✎» открывают один экран, устроенный как поиск: наша клавиатура внизу, строка ввода прямо над ней, список растёт снизу вверх — первое по алфавиту или лучшее совпадение ближе всего к пальцу. Отмеченные приложения подсвечены и с галочкой; счётчик «N из M выбрано» остаётся под заголовком. Работают смена раскладки, удаление, ввод рисунком по клавиатуре (подставляет лучшее название из списка). Клавиши изменения размера клавиатуры в этом экране нет, на её месте пусто (трактовка агента: размер настраивается в поиске). Иллюстрация совета «Настройте первый спейс» показывает строку «Добавить папку / Добавить приложение» только в режиме редактирования и новый экран выбора.
7. Экран выбора живёт в `:feature:search` рядом с клавиатурой (`AppPickerScreen`); `:feature:settings` получает его через слот `SettingsHost(pickers = …)`, который заполняет `:app`. Фичи по-прежнему не зависят друг от друга.
