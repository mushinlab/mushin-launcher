# ADR-0072. Фон нового спейса проявляется за 2 секунды, соседняя страница — без картинки

Статус: принято по указанию владельца, 2026-11-28. Меняет ADR-0060.

## Контекст
После ADR-0060 фон при смене спейса всё равно менялся резко: соседняя страница при листании и при смене из меню уже несла новую картинку, она въезжала вместе со страницей или проступала за 100–200 мс, а проявление за секунду работало только без соседней страницы. Владелец: резко, дёргано, неприятно; новая картинка должна проявляться за 2 секунды.

## Решения
1. **Соседняя страница без картинки.** Страницы листания и растворения рисуются только цветом палитры спейса; обои соседей больше не загружаются заранее (`SpacePager.warm/cool`, `SpacePage.background` удалены).
2. **Проявление за 2000 мс.** Когда меняется спейс, картинка главного экрана появляется из прозрачности за 2000 мс с замедлением в конце (`LinearOutSlowInEasing`); пока картинка нового спейса не загружена, прежняя не показывается. Смена картинки в том же спейсе — растворение за те же 2000 мс. Первый показ при запуске — без анимации. Это исключение из 200 мс (ADR-0003) по прямому указанию владельца; экран доступен сразу.
3. Цвет часов меняется синхронно с фоном, тоже за 2000 мс (ADR-0062). Параметр `fadeBackground` у `HomeScreen` удалён: проявление теперь всегда.
4. Новых зависимостей нет.

## Критерии приёмки
- **AC-72.1.** Given главный экран без фона, When фон появился, Then через два кадра фон почти не виден, через 2,2 с виден полностью.
- **AC-72.2.** Given листание к спейсу с картинкой, Then на соседней странице картинки нет; после переключения картинка проявляется за 2 с.
