# ADR-0013. Свой фон главного экрана из галереи с ползунком видимости

Статус: принято (указание владельца). Трактовки агента вынесены в «Открытые вопросы». 2026-10-15.

## Решения
1. **Где выбирается.** «Стиль → Фон → Выбрать изображение». Открывается системный выбор фото (Photo Picker): разрешение на доступ к галерее не нужно, лаунчер видит только выбранный снимок.
2. **Форматы.** Всё, что умеет системный `ImageDecoder`: PNG, JPEG, WebP, AVIF (а также HEIF, GIF — берётся первый кадр). Если файл не открылся, внизу экрана появляется сообщение «Не удалось открыть изображение».
3. **Хранение.**
   - Картинка уменьшается до размера экрана с запасом на обрезку, но не увеличивается.
   - Копия сохраняется во внутренней папке приложения (`files/background.webp`, WebP 90 %), оригинал в галерее не трогается.
   - Копия никуда не отправляется. Облачный бэкап и перенос на другое устройство уже выключены для всех файлов приложения.
   - Новых разрешений и зависимостей нет.
4. **Как рисуется.** Картинка растягивается на весь главный экран с обрезкой краёв. Поверх неё лежит слой цвета фона темы. Ползунок «Видимость фона» (0–100 %, шаг 5 %, по умолчанию 50 %) задаёт, насколько картинка проступает сквозь этот слой. Чётные строки списка становятся прозрачными, нечётные — полосой «зебры» той же видимости. На 100 % видна чистая картинка, на 0 % — обычная тема.
5. **Ползунок и «Убрать фон»** показываются только при выбранной картинке; кнопка выбора тогда называется «Сменить изображение».

## Открытые вопросы (трактовки агента)
| # | Вопрос | Решение агента | Альтернатива |
|---|---|---|---|
| Q-131 | Где показывать фон | Только главный экран | Ещё за панелями поиска и в настройках |
| Q-132 | Один фон или у каждого спейса свой | Один на все спейсы | Свой фон у спейса, как тема |
| Q-133 | Видимость по умолчанию | 50 % | Другое значение; затемнять картинку к тёмной теме |
| Q-134 | Качество копии | Размер экрана, WebP 90 % (быстро открывается при запуске) | Хранить оригинал без пережатия |
