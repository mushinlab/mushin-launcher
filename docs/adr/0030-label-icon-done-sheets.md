# ADR-0030. Иконка после текста, крупная галочка, шторки с тенью и выездом

Статус: принято (указание владельца; трактовки агента помечены). 2026-10-24. Изменяет ADR-0028 п. 3 и п. 5.

## Контекст
Владелец, после 0.4.0:
1. При выравнивании «по центру» текст стоит не по центру: его сдвигает иконка у правого края. Текст должен выравниваться по центральной линии экрана, а иконка — стоять сразу после текста, а не у правого края.
2. Галочка режима редактирования должна быть вдвое больше исходной кнопки.
3. Шторки режима редактирования должны быть без обводки, с тенью и плавно выезжать снизу вверх.

## Решения
1. **Строка главного экрана** (и «Добавить приложения»).
   - Иконка, если иконки включены, стоит сразу после текста, через прежний отступ 16 dp.
   - По левому краю: текст у левого отступа, иконка за ним.
   - По центру: центр текста (с отметками работы, счётчиком и свайпами) совпадает с центром строки, то есть с центральной линией экрана. Иконка выступает вправо. Ширина текста ограничена так, чтобы иконка помещалась с обеих сторон симметрично (трактовка агента).
   - По правому краю: текст с иконкой прижаты к правому отступу (трактовка агента).
   - В поиске иконки остаются у правого края: правка касалась главного экрана.
2. **Галочка.**
   - В режиме редактирования кнопка вдвое больше: подложка 80 dp вместо 40 dp, значок 44 dp вместо 22 dp.
   - Размер меняется переходом 200 мс (ADR-0003).
   - Кнопка вынесена из нижней панели и лежит поверх главного экрана на прежнем месте, правым краем и низом там же. Нижняя панель не растёт, и список не сдвигается при входе в режим (трактовка агента). Большая галочка может перекрывать правый край нижней строки, но строки в режиме не нажимаются.
3. **Шторки «Часы», «Текст», «Тема».**
   - Вместо обводки тень 24 dp.
   - При открытии шторка выезжает снизу вверх, при закрытии уезжает вниз, оба перехода 200 мс; затемнение под ней проявляется и гаснет.
   - Шторка рисунка в «Памяти» тоже без обводки и с тенью. Она появляется поверх уже открытой страницы, поэтому выезда у неё нет, как и раньше.
4. Анимации подсказок рисуют иконку и «+» сразу после текста.
