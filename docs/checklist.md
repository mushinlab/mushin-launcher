# Ручной чек-лист (T12.4)

Прогон на целевом Pixel 6 (Android 17) после установки release-сборки. Отмечать дату и результат.

## Роль и старт
- [ ] Первый запуск: карточка «Сделать лаунчером по умолчанию» над часами; тап → системный диалог; после подтверждения карточка исчезает (AC-01.1–01.2).
- [ ] Отказ в диалоге: карточка остаётся (AC-01.3). Роль отозвана в системных настройках → карточка снова видна после возврата (F01 Edge).
- [ ] Холодный старт: нет белой вспышки, первый кадр — палитра и избранное из снимка (D.14).

## Home
- [ ] Тап по строке запускает приложение без задержки (AC-03.3).
- [ ] fontScale 2.0: строки выше 64dp, лишние не рендерятся, в редакторе предупреждение (F03 Edge).
- [ ] Иконки NONE / LEFT / RIGHT; монохромные слои; белый квадрат → буква в круге (F04).
- [ ] Смена палитры перекрашивает иконки и системные бары в том же кадре (AC-04.5, AC-05.2).
- [ ] Приложение рабочего профиля: портфель; профиль на паузе → альфа 0,5, тап предлагает включить (AC-02.5).
- [ ] Приостановленное приложение: альфа 0,5, плашка «Приложение приостановлено» (F02 Edge).

## Жесты
- [ ] Двойной тап по фону → поиск с клавиатурой в первом кадре, системная клавиатура не появляется (F07).
- [ ] Long-press по фону и по строке → popup под пальцем, вибрация, движение пальца не запускает свайп (F06).
- [ ] Свайп вверх у нижнего края (жест «домой») не открывает поиск (C.4).
- [ ] Свайп вниз → шторка; если не работает — одна плашка за сессию (AC-12.3).
- [ ] Свайп влево/вправо от края экрана → системный back, не биндинг (C.4).

## Поиск и клавиатура
- [ ] «ыдфсл», «слак», «телеграм», «gm», «sber» — ожидаемые результаты (D.11).
- [ ] Цифры: свайп вверх с клавиши верхнего ряда и удержание 300 мс с пузырём (AC-08.3).
- [ ] Backspace: повтор после 400 мс, свайп влево очищает (AC-08.4).
- [ ] Быстрый набор двумя пальцами не теряет буквы (AC-08.8).
- [ ] Enter без результатов → вибрация REJECT (Q3).
- [ ] Recents: только запуски из поиска, без избранного энва, до 10 (F10).
- [ ] Аппаратная клавиатура: буква на Home открывает поиск; стрелки, Enter, Esc, Ctrl+Space (F14).

## Home / Back
- [ ] Home из поиска, popup, настроек → главный экран в том же кадре (AC-13.1).
- [ ] Возврат из приложения жестом «домой» → поиск закрыт и сброшен (AC-13.4).
- [ ] Back на чистом Home ничего не делает (AC-13.3).

## Данные
- [ ] Удаление приложения: строка исчезает из избранного, recents, жестов «(приложение удалено)» (Q12, AC-12.4).
- [ ] Переустановка в течение 30 дней возвращает переименование и скрытие (Q12).
- [ ] Удаление текущего энва переключает на «Обычный» (AC-05.5).

## Стабильность (G4)
- [ ] 14 дней ежедневного использования без падений.
- [ ] `adb shell run-as com.mushinlab.launcher cat files/exit_log.tsv` — нет строк с `MEMORY_LIMITER`.
- [ ] `adb shell dumpsys meminfo com.mushinlab.launcher` — PSS ≤ 60 МБ после 10 минут (D.14).

## Правки раунда 1 (ADR-0003)
- [ ] Свайп с привязкой к приложению: Home уезжает в сторону свайпа, без заметной пустой паузы перед приложением (Q-47).
- [ ] Свайп вниз по клавиатуре, строке запроса, recents и концу списка закрывает поиск; по середине длинного списка — прокручивает.
- [ ] Пикер: каждый тап сразу меняет фон строки и главный экран; нажатие видно даже при быстром тапе.
- [ ] Ввод рисунком: «maps», «slack», «telegram» и кириллические названия через транслит.

## Правки раунда 2 (ADR-0004)
- [ ] Ряд с пробелом той же высоты, что клавиши; между клавиатурой и полоской навигации — отступ в полклавиши.
- [ ] «Жест» слева в строке запроса включает панель рисунка, «АБВ» возвращает клавиатуру; режим сохраняется после закрытия поиска.
- [ ] Панель рисунка вдвое выше прежней; слово всегда из имени установленного приложения; «настройки» рисуются как nastroyki и показываются кириллицей.
- [ ] Задержка пальца ≥ 1 с — точка и вибрация, буква удваивается.
- [ ] Штрих исчезает после закрытия поиска, блокировки экрана и запуска приложения.
- [ ] Обучение: нарисовать жест, перерисовать, открыть нужное приложение; через 2–3 повтора тот же жест сразу даёт это приложение.
- [ ] Счётчик уведомлений: включить в «Главный экран», выдать доступ, цифра справа от названия обновляется вживую; при выключении цифры пропадают.
- [ ] Свайп вниз из верхней пятой части экрана — шторка, ниже — назначенное действие.
- [ ] Выбранные варианты в настройках подсвечены фоном, галочек нет.
- [ ] «Анимация нажатия»: все пять стилей заметны на строках Home-настроек и пикера.

## Правки раунда 3 (ADR-0005)
- [ ] Режим рисунка: «⌫» на месте числа результатов стирает слово; в режиме клавиатуры снова видно число.
- [ ] «Буквы на панели рисунка» показывают бледный QWERTY под штрихом, слова по буквам распознаются.

## Правки раунда 4 (ADR-0006)
- [ ] Слово, нарисованное заметно ниже или в стороне от букв (включить «Буквы на панели рисунка» для проверки), распознаётся.
- [ ] Рисунок слова, общего для двух приложений (например, «google»), показывает «варианты…» и оба приложения; «⌫» возвращает обычный список.
- [ ] После 1–2 выборов из вариантов тот же рисунок сразу даёт выбранное приложение.
- [ ] Значок Энва виден в «Приложения по умолчанию → Главный экран» и в диалоге выбора.
- [ ] Когда лаунчер по умолчанию другой, `adb shell monkey -p com.mushinlab.launcher -c android.intent.category.INFO 1` открывает Энв с плашкой «Сделать лаунчером по умолчанию».
- [ ] «Настройки → Система → Конфиденциальность» показывает текст политики.
- [ ] `./gradlew :app:checkReleasePermissions` зелёный; `:app:bundleRelease` с `keystore.properties` даёт подписанный ключом загрузки `.aab`.

## Правки раунда 5 (ADR-0007)
- [ ] Название в системе — «Mushin Launcher»; в настройках и меню — «Спейсы» / «Spaces».
- [ ] Telegram в спейсе и на свайпе; сменить его иконку в настройках Telegram — строка, свайп и переименование остаются.
- [ ] После установки новой сборки поверх старой порванная ранее привязка свайпа к Telegram снова работает.
- [ ] Ползунки в «Клавиатура → Распознавание рисунка» двигаются пальцем, значение меняется, «Вернуть значения по умолчанию» работает.
- [ ] Похожий рисунок для двух приложений: в строке запроса значки, тап по значку запускает.
- [ ] «Память»: приложение → миниатюры рисунков; «Забыть» убирает рисунок; «Стереть счётчики запусков» с подтверждением.
- [ ] «Цветные иконки» включаются в редакторе спейса и действуют только в этом спейсе.
- [ ] Удержание спейса в панели долгого нажатия 1 с открывает его редактор, короткий тап переключает.
- [ ] «Жесты»: свайпы и ввод рисунком на одном экране; в «Клавиатуре» их больше нет.
- [ ] Одиннадцать тем в редакторе спейса (от тёмных к светлым); белый текст в тёмных темах не режет глаз; старые спейсы получили новые цвета.
- [ ] Поиск: долгое нажатие → «Скрыть»; шестерёнка → «Показывать скрытые» показывает скрытые с пометкой, повторное нажатие прячет; после закрытия поиска режим сброшен.
- [ ] Приложение на свайпе: стрелка рядом с названием на Home и в поиске.
- [ ] Поиск — три отдельные скруглённые панели во всех одиннадцати темах, клавиши различимы.
- [ ] Полоска списка: сдвиг в одном спейсе не меняет положение в другом; после переключения туда и обратно список на своём месте.
- [ ] «Стиль → Фон»: картинка из галереи (PNG, JPEG, WebP, AVIF) на главном экране; ползунок видимости меняет её от темы до чистой картинки; «Убрать фон» возвращает тему; после перезагрузки телефона фон на месте.
